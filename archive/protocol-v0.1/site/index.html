全球倡议

我们只发起题目，不组织、不审核。谁想做就自己发一个仓库。

倡议 001

100 个城市，测一次自家自来水的 TDS

同一天、同一支笔、同一个读法。一个人测等于没测，一百个人测就是一张图。

征集中 · 需要的设备：TDS 笔 · 一个人 20 分钟
倡议 002

同款充电头，20 个城市同时测满载压降

网购同一批次，各自测，各自发仓库。看标称和实测差多少，也看不同城市的电网有没有影响。

征集中 · 需要的设备：万用表 + 电子负载 · 一个人 1 小时

怎么加入

不用申请，不用注册，不用经过任何人同意。三步，一下午。

1

拍一张工作台

桌面全貌 + 关键设备面板。手机拍就行，看得清型号最重要。

2

交给会看图的 AI

附上 SKILL.md。它会输出 lab.json、一个主页，和 3 个你能接的验证任务。

3

push 到 GitHub，打上 topic

带 gitscience-lab 的仓库，就会被索引器收进网络。

给 AI 的话（复制这段）

这是我的工作台照片。
请按 SKILL.md 生成：
1. lab.json
2. 一个能当仓库首页的 README
3. 3 个我现在就能做的实验

发布（三条命令）

git init && git add . && git commit -m "lab: init"
gh repo create lab --public --source=. --push
gh repo edit --add-topic gitscience-lab
