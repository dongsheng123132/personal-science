# 全球倡议

这是这个项目**唯一**由发起方做的事：出题。

不出钱、不派活、不审核、不排名。谁想做，就自己在自己的仓库里做一个实验，加一个 `challenge` 字段，索引器会把它们聚到一起。

```json
"challenge": "tds-100"
```

没有截止日期。凑够人就出一张图，凑不够就一直是"征集中"。

## 倡议 001 · `tds-100`

**100 个城市，测一次自家自来水的 TDS。**

| | |
|---|---|
| 测什么 | 总溶解固体（TDS），单位 ppm |
| 跟什么比 | 同城不同小区 / 不同城市 / 不同水源（自来水 vs 净水器出水） |
| 最少几次 | 同一杯水测 3 次，取中位数 |
| 大概多久 | 20 分钟 |
| 需要什么 | TDS 笔一支（约 ¥20–40） |
| 为什么值得 | 这是个几乎没人做过的、跨城市的公开基线。一个人测没有意义，一百个人测就是一张地图 |

**方案要点**（写进 `exp.json` 的 protocol）：

1. 早上第一次放水，先流 30 秒再取
2. 接一杯，室温放置 2 分钟
3. 测 3 次，记中位数
4. 记：城市、区、水源（自来水/二次供水/净水器出水）、TDS 笔型号、是否校准过

**判读方法**：不比"谁的水好"。比的是**同一品牌 TDS 笔、同一读法下，城市之间的分布**。任何"某地水质有毒"的结论都不在范围内。

**边界**：TDS 笔不是水质检测仪。它测的是导电性折算值，测不出细菌、重金属、余氯。**所有结果都不能当饮用水安全结论使用**，也不能写"检测报告"。

## 倡议 002 · `charger-20`

**同款充电头，20 个城市同时测满载压降。**

| | |
|---|---|
| 测什么 | 输出电压（V），在 25% / 50% / 100% 负载下 |
| 跟什么比 | 空载 vs 满载；不同城市样本之间比 |
| 最少几次 | 3 个负载点 × 3 次 |
| 大概多久 | 1 小时 |
| 需要什么 | 万用表 + 电子负载（或者大功率电阻 + 电流表） |
| 为什么值得 | 标称功率虚标是行业公开的秘密，但没人给出过"多地、多样本、同方案"的数 |

**方案要点**：

1. 统一样品（发起方公布批次和链接，各自买）
2. 空载测电压，记 3 次
3. 25% / 50% / 100% 负载各稳定 60 秒后测 3 次
4. 记录室温、万用表型号、电子负载型号

**判读方法**：先看**同一批货在不同人手里测出来差多少**——这个差值本身就是网络的噪声底。噪声底之内的差异不算差异。

## 怎么加入一个倡议

1. 照常做实验，`exp.json` 里加 `"challenge": "<倡议代号>"`
2. 仓库打上 `gitscience-exp` topic
3. 不用报名，不用告诉我们，索引器会自己收

## 发起一个倡议

理论上谁都可以。但为了让"倡议"这个词还有分量，v0.1 里只有发起方发布的倡议会显示在网站上。任何人可以在自己的仓库 README 里写"我想搞 XXX"，那叫**号召**，不叫倡议。

## 倡议的三条规矩

1. **不涉及人身安全**：不测高压、不拆电池、不碰化学品、不做需要资质的项目
2. **不针对具体商家**：倡议是"测一类东西"，不是"打假某一家"
3. **必须公开方案**：没有预注册方案的倡议，不做
