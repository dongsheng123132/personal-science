## protocol-v0.1/

第一版的想法：给"实验"做一套 GitHub 协议——`lab.json` / `exp.json` / `rep.json`，打 topic 加入网络，索引器扫全网生成网站，核心创新是"复现不走 PR、放复现者自己仓库"。

做出来了一整套：三个 JSON Schema、索引器（本地 + GitHub 双模式）、静态网站、5 个示例实验室、复现关系图。

**为什么折叠**：限制太多。要写 JSON、要理解三个对象、要装 Python、要跑索引器。一个人想分享一个实验，不该先学一套协议。

**里面有价值的东西**：

- "复现记录必须放在复现者自己仓库里" —— 这条仍然成立，只是现在用 `RESULTS.md` 一行代替
- `SKILL.md` 里"照片推断必须标未确认"的纪律 —— 保留在新版 SKILL 里

现在的方向是 [README.md](../README.md)：一个清单，一条 PR，完事。
