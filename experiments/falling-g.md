# 手机慢动作测 g

> 用一段 240fps 视频和一把尺子，量出重力加速度。

| | |
|---|---|
| **需要** | 手机（支持慢动作/高帧率）、米尺、胶带、一个能重复下落的小物体（硬币、橡皮） |
| **时间** | 30 分钟 |
| **花费** | ¥0 |
| **难度** | ★☆☆ |
| **验收** | 算出的 g 落在 8.5–10.5 m/s² |

## 为什么值得做

重力加速度是你能在地球上最"随手"测到的物理常数之一。而且它不需要任何仪表——**你自己的手机就是一台 240 帧每秒的高速摄像机**。

## 怎么做

1. 把米尺用胶带竖直贴在墙上，零点朝上（下落起点在 0 附近）。
2. 手机横过来，用支架/书堆固定，镜头正对尺子，距离 1–1.5 米。**手机要正对，不要仰拍**。
3. 开慢动作（240fps 或 120fps，记下你用的是哪个），开始录，然后松手让物体落下。松手时手别给力。
4. 回放视频，**逐帧**看：找到物体刚离开手的那一帧，和它经过某个刻度的那一帧。
5. 数帧数 `n`，时间 `t = n / 帧率`。量下落距离 `s`（从起始位置到那一帧位置的差）。
6. 算 `g = 2s / t²`。

重复 3 次，取平均。

## 算一下

1 米自由落体大约 **0.45 秒**，240fps 下约 **108 帧**：

```
t = 108 / 240 = 0.45 s
g = 2 × 1.00 / 0.45² ≈ 9.9 m/s²
```

如果算出来明显不是 9.8（比如 20 以上），八成是帧数数错了，或者视频帧率和你想的不一样——回去查视频元数据，重数一遍。

## 坑

- **帧率要看视频元数据**，不是你以为的。有的手机"240fps"实际是 120fps 播放，用播放器/编辑器查编码信息。
- 手机必须正对尺子。仰拍/俯拍会让刻度看起来不等距，直接毁掉结果。
- 尺子的零点要对准物体开始下落的真实位置。
- 松手瞬间手会给一个初速度，慢动作才看得出来——多拍几次，挑最干净的那条。
- 空气阻力会让轻物体偏小，用硬币/小石头这类密度大的。

## 想再往前一步

- 换成 `s = ½gt²` 的多点拟合：逐帧记位置，画 `s–t` 图，拟合二次项系数。
- 用同一个视频验证"真空 vs 空气"：纸片和硬币同时落，慢放看谁快。
- 换个海拔/城市测，看有没有差别（差别很小，能测出来算你厉害）。

## 安全

别砸到脚，别从高处往下丢东西（尤其窗外）。
