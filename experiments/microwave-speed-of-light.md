# 微波炉测光速

> 用一台微波炉和一排巧克力，把光速量出来。

| | |
|---|---|
| **需要** | 微波炉（转盘能取下来的）、巧克力片或棉花糖、尺子、纸盘 |
| **时间** | 30 分钟 |
| **花费** | ¥10 |
| **难度** | ★☆☆ |
| **验收** | 算出的 c 落在 2.4–3.4×10⁸ m/s 之间 |

## 为什么值得做

微波炉里的微波频率是固定的 2.45 GHz。它在炉腔里形成驻波，波峰的地方加热快、波谷的地方几乎不加热。所以巧克力融化的斑点不是随机的——**相邻两个融化点正好隔半个波长**。

量出这半个波长，乘以频率再乘 2，就是光速。一台厨房家电，一个 1676 年之后就没变过的常数。

## 怎么做

1. **取下转盘和转盘架。** 这一步最重要，转盘会带着驻波图案一起转，量不出来。
2. 铺一张纸盘，把巧克力片排成一条直线，间隔约 1 cm，横跨整个炉腔。
3. 中火加热 **15–20 秒**，看到出现两三个明显融化的点就停，不要等全化。
4. 立刻取出（烫），量相邻两个**融化中心**之间的距离 `d`。量 3–4 段取平均。
5. 算：波长 `λ = 2d`，光速 `c = λ × 2.45×10⁹`。

## 算一下

典型结果 `d ≈ 6.1 cm`：

```
λ = 2 × 0.061 m = 0.122 m
c = 0.122 × 2.45×10⁹ = 2.99×10⁸ m/s
```

误差 10% 以内算正常，5% 以内算手稳。

## 坑

- **别用转盘**，用了就只能看到一片糊。
- 加热太久，波峰波谷都化了，斑点分辨不出来。
- 巧克力要平铺，叠起来会因为热传导互相影响。
- 微波炉标称 2.45 GHz，实际每台有几十 MHz 偏差，这是主要误差来源之一。
- 不要用带金属边的盘子、锡纸、金边杯子。

## 想再往前一步

- 换棉花糖重做，融化边界更清晰。
- 用红外测温枪扫一遍炉腔，画温度分布，找波峰间距。
- 同一台炉测 3 次，看重复性；换一台炉再测，看差异。

## 安全

只加热食物。不要空转。不要改装或拆开微波炉。**不要测门缝的"泄漏"**——没必要，而且有风险。
