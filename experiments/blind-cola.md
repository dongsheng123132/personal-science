# 盲测可乐

> 一套正经的盲测，检验"你真喝得出来吗"。

| | |
|---|---|
| **需要** | 可口可乐、百事可乐（同温、同批次尽量）、纸杯、一个不知情的帮手 |
| **时间** | 1 小时 |
| **花费** | ¥15 |
| **难度** | ★☆☆ |
| **验收** | 10 轮里正确 ≥8 轮才算"真喝得出来" |

## 为什么值得做

这是一个**关于实验设计本身的实验**。你会第一次亲手体会到：安慰剂、主观预期、单盲/双盲，这些词不是论文里的装饰品——你自己就会被骗。

而且它的结论可以很反直觉：大多数人喝不出来。

## 怎么做

1. **先定死判定标准**：10 轮里正确 ≥8 轮算"能分辨"。为什么是 8？见下面"算一下"。
2. 找一个帮手。你把两种可乐倒进标着 A、B 的杯子，然后**转过身**，让帮手随机交换或不动（帮手不知道你在测什么更好）。
3. 你只拿到两杯，尝完说"哪杯是可口可乐"。
4. 每轮之间用水漱口，停 1 分钟。
5. 记录 10 轮结果。

**单盲**：你不知道顺序。**双盲**：倒可乐的人也不知道哪杯是哪杯（用编号 + 另一个人记录）。至少做到单盲。

## 算一下

纯靠猜，10 轮里猜对 ≥8 轮的概率：

```
P = [C(10,8) + C(10,9) + C(10,10)] / 2¹⁰
  = (45 + 10 + 1) / 1024
  ≈ 5.5%
```

低于常用的 5% 显著性线（刚好卡在边界）。所以"8/10"是个合理但不严格的合格线，**9/10 或 10/10 才更有说服力**。

如果你的结果是 5/10、6/10——不是"失败"，这就是结论：**你分不出来**。

## 坑

- 温度必须一致（冰的 vs 常温的差别远大于品牌差别）。
- 气泡状态不同（开瓶时间、倒法）会暴露信息。
- 杯子要一样，最好用不透明的纸杯。
- 你自己当被试又当主试，很容易不自觉作弊——哪怕只是看到倒的顺序。
- 喝多了味觉会疲劳，10 轮足够。
- 两种可乐在不同地区配方/甜味剂可能不同（尤其国产 vs 进口），这不是实验误差，是另一个变量。

## 想再往前一步

- 换成"无糖 vs 有糖"，看你能不能分出来。
- 加一组"专家"（自称很懂的人），比较样本量和成绩。
- 换不同价位的矿泉水/橄榄油/咖啡豆，同一套方法。
- 把顺序设计成随机区组，做 20 轮，算置信区间。

## 安全

糖分摄入适量。别让未成年人参与饮酒类盲测（本清单不涉及）。
