# 杨氏双缝：用激光笔看见光的波动性

> 一根激光笔、一片双缝、一面白墙。光穿过两条细缝，墙上出现一排明暗条纹。

| | |
|---|---|
| **需要** | 激光笔（<5mW）、双缝片或衍射光栅（¥10–20）、卷尺、白纸贴硬板、手机 |
| **时间** | 40 分钟 |
| **花费** | ¥20–40 |
| **难度** | ★☆☆ |
| **验收** | 反推的波长与激光笔标注值偏差 < 15%；或头发直径测量重复性 < 10% |

## 为什么值得做

1801 年，托马斯·杨用这个实验把"光是波"钉死。今天你在客厅就能重做一遍。

更有意思的是：**你不只是"看见"条纹，你能从条纹间距反推出光的波长**——把看见变成测出。这一步，是业余和科学的区别。

而且它有个便宜的副产品：没有双缝片，用一根头发也能做，顺便量出头发有多粗。

## 怎么做

### 路线 A：双缝干涉（主实验）

1. **晚上关灯**，或拉上窗帘。暗室效果最好。
2. 激光笔**固定在书堆上**，别用手拿（手抖会让条纹糊掉）。
3. 双缝片贴在激光笔前方 5 cm 处，让光斑正好穿过两条缝，打到 2 米外的白纸上。
4. 墙上出现一排明暗相间的条纹。用手机拍照（**关闪光灯**），旁边放一把尺子当比例尺。
5. 量相邻亮纹间距 `Δy`。**量 5 个间距除以 5**，比只量一个准。
6. 算：

```
λ = Δy · d / L
```

`d` 是双缝间距（双缝片上会标，常见 0.1 mm 或 0.2 mm），`L` 是缝到墙的距离。

### 路线 B：没有双缝片？用头发丝（单缝/障碍物衍射）

1. 头发拉直，两端用胶带固定在激光笔出光口上，让头发**横跨整个光斑**（光束要比头发宽）。这样中央是头发的影子，两旁是对称的衍射明暗纹。**别让光只从头发一边擦过**——那只有单边衍射，出不来对称条纹。
2. 墙上同样会出现一排明暗条纹。
3. 量相邻暗纹间距 `Δy`，反推：

```
d = λ · L / Δy
```

你就量出了一根头发的直径（通常 60–80 µm）。这大概是普通人最便宜的"微米级测量"。

## AI 可以怎么帮你

这一页的核心不是"照着做"，是"让 AI 把这件事做得更准、更快"。可以直接用的五个动作：

**1. 先算参数，别做废了**
> "激光笔 650nm，双缝片 d=0.1mm，我想把条纹间距控制在 1 厘米左右，L 应该取多少米？"

AI 一秒钟给出 `L ≈ 1.5 m`，你就不用先摆好再发现间距只有 2 毫米量不出来。

**2. 让它写测量脚本**

拍好照片发给 AI，附一句：

> "这张图是双缝干涉条纹，旁边有尺子。写一段 Python（OpenCV），自动找出亮纹中心位置，算平均间距，并输出像素→毫米的换算。"

它会给你一段能跑的代码。**你负责拍好图，AI 负责数条纹**——这比手量准，也更像"用 AI 做科研"。

**3. 让它算误差**

> "这个实验里，λ = Δy·d/L。请列出所有误差来源，估算每项占多大，告诉我哪一项最该改进。"

它会告诉你：`L` 量不准的影响可能比条纹中心判定更大，于是你知道该把卷尺拉直，而不是纠结照片。

**4. 让它扮演审稿人**

> "这是我打算做双缝实验的步骤，请你找出会让实验失败的地方，越刻薄越好。"

这条比前三条都值钱。它会挑出你没注意的：缝和墙不平行、激光笔没固定、白纸有反光。

**5. ESP32 升级版**

用光敏电阻或光电二极管 + 步进电机，让传感器自动横扫条纹，画出光强分布曲线。AI 帮你写 Arduino 代码和拟合峰位——这已经不是"看条纹"，是自制一台光谱仪。

## 算一下

`d = 0.1 mm`，`L = 2 m`，`λ = 650 nm`：

```
Δy = λ·L/d = 650e-9 × 2 / 1e-4 = 0.013 m = 1.3 cm
```

墙上每隔 1.3 厘米一条亮纹，肉眼看清、尺子好量。

## 坑

- **激光绝不能直视**，也不能对着人和镜面。
- 手拿激光笔一定抖，必须固定。
- 缝要和墙**平行**，否则条纹是斜的，量出来偏大。
- 双缝片上的 `d` 要看清：0.1 mm 还是 0.2 mm，差一倍。
- 白墙不平（有散斑）会让条纹边界糊，白纸贴在硬板上更好。
- `L` 对结果影响很大，卷尺拉直、从缝量到纸面。

## 想再往前一步

- 换红/绿/蓝三种激光笔，验证**波长越短、条纹越密**。
- 把双缝换成三缝、多缝，看条纹怎么变锐。
- 用头发量完直径，再和显微镜下对比。
- 单光子版（仅阅读）：一次只放一个光子，条纹仍然会慢慢出现——量子力学最反直觉的一张图。

## 安全

激光 <5mW 在正常使用下安全，但**绝不直视、绝不对着人和反射面**。做完立刻关掉。
