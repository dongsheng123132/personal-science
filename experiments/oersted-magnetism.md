# 奥斯特实验：电流让磁针偏转

> 一根导线、一节电池、一个指南针。通电的一瞬间，磁针动了——电和磁原来是一回事。

| | |
|---|---|
| **需要** | 一节 AA 电池、约 1 米导线、指南针、一个 3Ω 5W 电阻（限流用）、开关（可选） |
| **时间** | 30 分钟 |
| **花费** | ¥10 |
| **难度** | ★☆☆ |
| **验收** | 通电后磁针偏转 ≥10°，断电回正；电流反向，偏转也反向（绕 2–3 圈更明显）|

## 为什么值得做

1820 年，奥斯特在一次讲课时，意外发现通电导线旁边的磁针动了。人类第一次把"电"和"磁"连在了一起——电动机、发电机、变压器，全部从这里开始。

你花十分钟就能亲手让一根磁针听你的话。

## 怎么做

1. 指南针平放桌上，等磁针稳定（针大致指向南北）。
2. 把导线沿**南北方向**拉直，架在指南针正上方约 1 厘米处。
3. 电路：电池 → 3Ω 电阻 → 导线 → 电池。**串上电阻是为了限流**，别把导线直接短路到电池上（会烫手）。
4. 接通电路 2 秒，看磁针偏转多少度；断开，看它是否回正。
5. 把电池正负极反过来，再通一次——磁针往另一个方向偏。
6. 把导线在指南针上方绕 2–3 圈（线圈更明显），重复。

## 为什么磁针会动

通电直导线周围有环形磁场，大小（近似）：

```
B = μ₀·I / (2πr)
```

`I = 0.5 A`、`r = 0.01 m` 时，`B ≈ 1×10⁻⁵ T ≈ 0.1 Gauss`，和地球水平磁场（约 0.3 Gauss）同一个量级——所以磁针会被"扳"出一个明显的角度。绕 2 圈、电流加大，偏转会更大。

## AI 可以怎么帮你

- **先算该用多大电阻**：
  `一节 AA 电池 1.5V，我想让电流在 0.5A 左右、导线别发烫，串多大电阻？功率要几瓦？`
- **解释方向**：
  `我把通电导线放指南针上方，磁针往东偏。用右手定则说明磁场方向，并画一个俯视图。`
- **做定量版**：
  `我测了不同电流下磁针的偏转角：0.2A→10°、0.4A→20°…… 请画 I–角度 图，并估算比例关系（小角度近似下角度∝I？）。`
- **抓错**：
  `磁针完全不动，可能是什么原因？按可能性排，逐条给检查方法。`

## 坑

- **直接短路电池**：导线电阻接近 0，电流很大，几秒就烫。必须串限流电阻。
- 磁针会被附近的铁器、手机、耳机磁铁干扰，先清场。
- 通电太久磁针会被磁化偏掉，每次只通 2 秒。
- 导线要离指南针近（≤1cm），远了磁场衰减很快。

## 想再往前一步

- 换线圈（绕 10 圈、50 圈），验证偏转随圈数增大。
- 把"电生磁"反过来——正是奥斯特实验之后法拉第做的事（见本仓库法拉第电磁感应）。
- 用手机指南针传感器 + 通电线圈，做一张磁场随距离的衰减曲线。

## 安全

一节 AA 电池 + 限流电阻，安全。别把电池直接短路，别用锂电池（内阻太低，短路电流大）。
