# 自来水 TDS 对照

> 20 块钱的笔，量出你家水的"导电性"。

| | |
|---|---|
| **需要** | TDS 笔（¥20–40）、几个干净杯子 |
| **时间** | 20 分钟 |
| **花费** | ¥20 |
| **难度** | ★☆☆ |
| **验收** | 同一杯水测 3 次，读数差异 < 10% |

## 为什么值得做

TDS 笔测的是水的电导率折算值（ppm）。它便宜、快、能重复，是少数适合**很多人同时做、然后横向比**的实验。

一个人测自己的水没有意义。十个城市、一百个人测，才有对照。

## 怎么做

1. 准备 4 杯水：自来水（先放水 30 秒）、烧开后的自来水、净水器出水、瓶装矿泉水。
2. 每杯测 3 次，**取中位数**（不是平均，避免偶发跳变）。
3. 每次测之间用纯净水冲一下探头，擦干。
4. 记下：水温、笔的型号、有没有校准过。
5. 排列对比。

## 算一下

典型量级（仅供参照，各地差别很大）：

| 水样 | TDS 大致范围 |
|---|---|
| 纯净水 / RO 出水 | 0–20 ppm |
| 瓶装矿泉水 | 30–300 ppm |
| 自来水（南方） | 50–200 ppm |
| 自来水（北方部分地区） | 200–500 ppm |

读数随温度变化，一般笔内有温度补偿，但不同水温下仍会有偏差——所以**同一批测试最好记录水温**。

## 坑

- **TDS 不是水质检测。** 它测不出细菌、病毒、重金属、余氯、有机物。任何"水能不能喝"的结论都不在这个实验范围内。
- 探头要冲洗擦干，不然上一杯会污染下一杯。
- 气泡会让读数跳动，等稳定再读。
- 笔要定期用纯净水校准（很多笔有一个 CAL 键）。
- 同一支笔在不同人手里可能差 10%，跨人比较时要写清楚用的什么笔。

## 想再往前一步

- 和不同城市的朋友约同一天测，做一张"全国自来水 TDS 分布图"。
- 加一组：同城不同小区、新房/老房。
- 测一壶水反复烧开 5 次，看 TDS 有没有变化（浓缩效应）。
- 净水器前后对比，看滤芯还有没有效。

## 安全

无。别喝实验水样以外的奇怪东西。
