# 自来水 TDS 对照

> 20 块钱的笔，量出你家水的"导电性"。

| | |
|---|---|
| **需要** | TDS 笔（¥20–40）、几个干净杯子 |
| **时间** | 20 分钟 |
| **花费** | ¥20 |
| **难度** | ★☆☆ |
| **验收** | 同一杯水测 3 次，读数差异 < 10% |

## 为什么值得做

TDS 笔测的是水的电导率折算值（ppm）。它便宜、快、能重复，是少数适合**很多人同时做、然后横向比**的实验。

一个人测自己的水没有意义。十个城市、一百个人测，才有对照。

## 这件事为什么重要

**当年**：19 世纪电导率测量进入水质分析，成为判断溶解离子的快捷手段。

**现在**：TDS 笔二十块钱，能对比自来水、矿泉水、净水器出水；一个人测没意义，一百个人测才有对照。

**对后来的影响**：电导率换算离子浓度，成了环境监测和工业水处理的常规指标。

**AI 时代还能做什么**：汇总多人数据，AI 画城市分布图、找异常值，把「我家水怎么样」变成地区差异。

## 最小版本（15 分钟）

一杯自来水、一杯瓶装水、一杯纯净水（或凉白开），一支 TDS 笔。

1. 三个杯子各倒 100 mL，**同温**放半小时（水温高于 40℃ 读数会失真）
2. TDS 笔探头浸入，等读数稳定 5 秒，记数
3. 每换一种水，先用待测水涮两遍探头
4. 每种水测 3 次取平均

**测什么**：自来水通常 100–300 ppm，纯净水 < 30 ppm，矿泉水可能更高（含矿物质）。

**两个必须知道的误读**：
- **TDS 高 ≠ 脏**：矿泉水里的钙镁离子也算 TDS。
- **TDS 低 ≠ 安全**：糖、细菌、病毒都不改变 TDS，测不出来。
- 凉白开不是纯水，煮沸会让矿物质浓缩，读数可能比自来水还高。

**注意**：TDS 笔测的是电导率折算值，不是水质检测仪；定期用标准液校准。

## 怎么做

1. 准备 4 杯水：自来水（先放水 30 秒）、烧开后的自来水、净水器出水、瓶装矿泉水。
2. 每杯测 3 次，**取中位数**（不是平均，避免偶发跳变）。
3. 每次测之间用纯净水冲一下探头，擦干。
4. 记下：水温、笔的型号、有没有校准过。
5. 排列对比。

## 算一下

典型量级（仅供参照，各地差别很大）：

| 水样 | TDS 大致范围 |
|---|---|
| 纯净水 / RO 出水 | 0–20 ppm |
| 瓶装矿泉水 | 30–300 ppm |
| 自来水（南方） | 50–200 ppm |
| 自来水（北方部分地区） | 200–500 ppm |

读数随温度变化，一般笔内有温度补偿，但不同水温下仍会有偏差——所以**同一批测试最好记录水温**。

## 坑

- **TDS 不是水质检测。** 它测不出细菌、病毒、重金属、余氯、有机物。任何"水能不能喝"的结论都不在这个实验范围内。
- 探头要冲洗擦干，不然上一杯会污染下一杯。
- 气泡会让读数跳动，等稳定再读。
- 笔要定期用纯净水校准（很多笔有一个 CAL 键）。
- 同一支笔在不同人手里可能差 10%，跨人比较时要写清楚用的什么笔。
