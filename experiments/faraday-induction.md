# 法拉第电磁感应：让磁铁"发一次电"

> 磁铁插进线圈，线圈两端冒出电压。今天全球所有的发电厂，都只是这条规律的工程化。

| | |
|---|---|
| **需要** | 一个线圈（手绕 100 圈以上，或用电机里拆的线圈）、强磁铁、万用表（交流 mV 档）或手机录音当示波器 |
| **时间** | 40 分钟 |
| **花费** | ¥20 |
| **难度** | ★★☆ |
| **验收** | 磁铁进出线圈时电压明显超过噪声；磁铁越快电压越高；磁铁换方向电压也换向 |

## 为什么值得做

1831 年，法拉第发现：**变化的磁场在线圈里产生电压**。这是"电生磁"的反向——"磁生电"。

你今天能做的每件事，从手机充电到电动汽车，都靠它。

## 怎么做

1. 手绕一个线圈：找一根塑料管/笔杆，绕 100–200 圈漆包线或细导线，两端留出线头。
2. 线圈两端接万用表 **DC mV 档**。单次插/拔是单脉冲，DC 档能看到跳变；AC 档是交流耦合、按正弦 RMS 标定、低频响应差，单脉冲很可能读 0。
3. 磁铁快速插进线圈、再抽出，看指针/读数跳动。
4. 记录：插进和抽出时，电压方向（正负）是不是相反。
5. 变化速度：慢插、快插，对比峰值电压。
6. 换更强的磁铁、或把两个磁铁叠起来，再比。

## 为什么有电压

法拉第定律：

```
V = -N · dΦ/dt
```

`N` 是圈数，`dΦ/dt` 是磁通量变化的速度。所以：**圈数越多、磁铁动得越快、磁铁越强，电压越高**；磁铁不动，电压为零。

## AI 可以怎么帮你

- **估电压**：
  `100 圈线圈，直径 2cm，磁铁表面场强约 0.3T，我 0.1 秒把磁铁插入。估一下感应电压大概几毫伏？万用表 mV 档够不够？`
- **用手机当示波器**：
  `我没有示波器，怎么用手机录音口 + 音频线把感应电压录下来看波形？写清楚接线和软件。`
- **画波形解释方向**：
  `插进和抽出时电压一正一负，为什么？结合楞次定律解释，并画磁铁位置-电压草图。`
- **升级成发电机**：
  `能不能把磁铁改成旋转的、线圈固定，做一个小发电机点亮 LED？给出具体结构和零件。`

## 坑

- **单次插拔用 DC mV 档**看跳变/峰值保持；只有连续快速往复时 AC 档才有意义。有示波器或手机录音口更好。
- 万用表 mV 档可能看不到（电压太小），先绕 100 圈以上、用强钕磁铁。
- 磁铁别靠太近信用卡、硬盘、手机指南针。
- 线圈线头氧化会导致读数不稳，刮亮再夹。

## 想再往前一步

- 测峰值电压随速度变化，画 V–速度 图，验证近似线性。
- 绕 50 圈 / 100 圈 / 200 圈各做一次，验证 V ∝ N。
- 把磁铁装在自行车辐条上、线圈固定在车架，骑一圈看能不能点亮 LED——你就做了一台发电机。

## 安全

低电压，安全。强钕磁铁注意夹手，别吞下小磁铁。
