## 为什么值得做

1798 年卡文迪许用一根扭丝和几个铅球，第一次"称"出了地球的质量。他测的不是地球，是两个球之间的引力——小到约 10⁻⁷ N，比一根头发丝的重量还小。

这件事的价值不在数字，在方法：**把看不见的力，转成一个看得见的位移，再用光杠杆把位移放大几十倍。** 你今天重做，测不准是正常的，但你会亲手体验"用放大和对照把微弱信号从噪声里捞出来"这套测量思维。它比任何科普视频都硬。

## 怎么做

**1. 做扭秤（核心）**

- 取一根 30–40 cm 的细金属丝，上端固定在架子横梁上，下端挂一根轻质横杆（细木条或碳纤维杆，长约 20 cm）。
- 横杆两端各粘一个小球（直径 1–2 cm），两球等距、对称。这是"哑铃"。
- 在横杆中点、扭丝正下方粘一小块镜子，镜面竖直。
- 整个哑铃必须能绕扭丝自由转动，且**静止时横杆水平**。

**2. 装光杠杆**

- 激光笔固定在 2–3 m 外，对准小镜子。
- 反射光打到墙上或纸板上，记下光斑位置。
- 镜子转 θ，光斑移动约 2θ × 距离。距离越远，放大越大。3 m 处，镜子转 0.01 rad，光斑移约 6 cm。

**3. 加外力球**

- 两个大球放在哑铃两端外侧，对称放置，靠近小球。
- 先让系统静置到光斑不再漂移（可能要 10–30 分钟，扭丝在蠕变）。
- 记下光斑位置 A。
- 把两个大球**同时换到另一侧**（左右对调），引力方向反转。
- 等系统重新稳定，记下光斑位置 B。
- 移动量 Δ = |B − A|。

**4. 对照实验（必做）**

- 把大球拿远（比如移到 1 m 外），重复换位操作，看光斑是否还移动同样多。
- 如果拿远后移动明显变小，说明你测到的确实是球的引力，不是温度/气流/地面震动。

**5. 记录**

- 每次测量记：时间、光斑位置、室温、大球位置。
- 至少做 5 组换位，取平均。

## 算一下 / 会看到什么

引力公式：

```
F = G (m_1 m_2)/(r^2)
```

扭丝回复力矩：

```
\tau = k\theta
```

平衡时：

```
k\theta = 2 F L
```

（L 是横杆臂长，两个球各贡献一份力矩。）

光杠杆放大：

```
Δ = 2\theta D
```

（D 是镜到墙距离。）

合并：

```
G = (k \theta r^2)/(2 m_1 m_2 L) = (k Δ r^2)/(4 D m_1 m_2 L)
```

**你会看到什么：**

- 大球换位后，光斑在几十秒到几分钟内缓慢移动，然后停在新位置。
- 移动量通常只有几毫米到几厘米——取决于你的扭丝有多软、镜子到墙有多远。
- 拿远大球后，移动量明显变小。这是你成功的信号。

**数量级预期：** 家庭条件下，k 很难标定准确，所以 G 的绝对值大概率偏几倍甚至一个数量级。**验收只看数量级**，不看小数点。

## 坑

1. **扭丝太硬。** 这是最常见的失败。丝越粗，转角越小，光斑几乎不动。先用最细的丝，宁可周期长、等得久。
2. **气流。** 人走动、呼吸、空调风都会推横杆。必须用纸板或塑料箱做挡风罩，测量时人退开。
3. **温度漂移。** 手靠近、灯光照射会让扭丝和架子热胀，光斑缓慢单向漂。测前静置 20 分钟，测量时别碰架子。
4. **地面震动。** 走路、关门都会传进来。测量时站着不动，或把架子放在厚书/海绵上。
5. **镜子没粘正。** 镜面必须竖直且与横杆垂直，否则光斑移动被几何误差吃掉。
6. **大球换位不对称。** 两个大球必须同时、对称换位，否则引入额外力矩。
7. **过早读数。** 扭秤有阻尼，稳定需要时间。看光斑 1 分钟不动了再记。
8. **只做一次。** 单次数据没有对照，说明不了任何事。至少 5 组 + 拿远对照。

## 想再往前一步

- **标定扭丝常数 k：** 给横杆加一个已知的小力矩（比如挂一个已知质量的小砝码在已知臂长上），测转角，反算 k。这样 G 的绝对值能收窄。
- **测扭转周期 T：** 让哑铃自由扭动，测周期，用 $k = 4\pi^2 I / T^2$ 算 k（需要估转动惯量 I）。
- **换更软的丝：** 钨丝或石英丝（待核实可得性），转角更大，信号更强。
- **做真空/恒温罩：** 减少气流和温度影响，这是卡文迪许当年的关键改进。

## 安全

- 激光笔 **<5 mW**，不要直射眼睛，不要对着人和窗户。反射光也别盯着看。
- 铅球有重量，别砸脚；铅表面别用手长时间摸，摸完洗手。
- 架子要稳，重球放低处，防止倾倒。
- 细金属丝末端可能扎手，剪断后把尖端弯回。
- 不涉及高温、高压、化学品、电。一个人在家可做。
