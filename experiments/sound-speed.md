# 拍手测声速

> 拍一下手，听回声，算出声速。

| | |
|---|---|
| **需要** | 手机（录像）、卷尺或步测、一面够远的硬墙或长走廊 |
| **时间** | 20 分钟 |
| **花费** | ¥0 |
| **难度** | ★☆☆ |
| **验收** | 20°C 时算出 330–350 m/s |

## 为什么值得做

声速是最容易"听出来"的物理量。你只需要一声拍手和一面墙，就能在两个声音的间隔里读出它。

## 怎么做

1. 找一面硬墙（砖墙、瓷砖、大楼外墙），站在离它 **至少 15 米**的地方。越远越准。
2. 用手机**录像**（要带声音，方便对时间轴），对着墙的方向拍手。
3. 回放，看波形：第一个峰是拍手声，第二个峰是回声。量两者时间差 `t`。
4. 量距离 `d`（手机到墙），声速 `v = 2d / t`。
5. 换 3 个距离各做一次，取平均。
6. 记下气温 `T`，做一个修正：`v ≈ 331 + 0.6T`（20°C 时 ≈ 343 m/s）。

## 算一下

`d = 30 m`，时间差 `t = 0.175 s`：

```
v = 2 × 30 / 0.175 = 343 m/s
```

正好是 20°C 时的声速。

## 坑

- 距离太近（<10m），两个声音会糊在一起，分不开。
- 回声太弱：墙要硬、要大，环境要安静。软墙、树、窗帘吸音。
- 风、背景噪声会淹掉回声。
- 手机麦克风和扬声器都有延迟，但两个声音走的是**同一个**麦克风，延迟抵消，所以不影响时间差。
- 用录像而不用录音，是因为录像能顺便确认"这一下拍手"是哪一声。

## 想再往前一步

- 换不同温度/湿度重复，验证温度修正。
- 用两个手机：一个在远处拍手，一个在近处录，测单向传播时间。
- 在走廊里制造多次回声，看能不能分辨出 2 次、3 次反射。
