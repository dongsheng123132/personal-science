# 温度计 + 秒表量热平衡

> 一杯热水放进冰箱，量出它"凉得有多慢"。

| | |
|---|---|
| **需要** | 温度记录仪（USB 的约 ¥20）或温度计 + 秒表、冰箱、杯子（最好两种材质） |
| **时间** | 2 小时（可以不管它，让它自己记） |
| **花费** | ¥20 |
| **难度** | ★☆☆ |
| **验收** | 画出 ln(T−T环境) 对时间的直线，算出时间常数 τ |

## 为什么值得做

热水变凉不是线性的，是**指数衰减**。这个曲线里藏着一个数字：时间常数 τ——它决定了"凉到一半要多久"。

同样的数学出现在放射性衰变、电容放电、疫苗冷链、咖啡保温里。用一杯水把它玩明白，比背公式划算。

## 怎么做

1. 倒一杯热水（**60–70°C，别更烫**，保护冰箱），把温度记录仪放进去。
2. 放进冰箱，记录环境温度（冰箱内温度）。
3. 每 1 分钟记一次水温，记到接近冰箱温度为止（约 60–90 分钟）。
4. 算 `T − T环境`，取自然对数，画 `ln(T−T环境)` 对时间 `t`。
5. 斜率 = `−1/τ`，所以 `τ = −1/斜率`。
6. 换一个保温杯、一个薄玻璃杯重做，对比 τ。

## 算一下

初温 65°C，冰箱 4°C，环境温差 61°C。
如果 18 分钟后温差降到 22°C：

```
ln(61) = 4.11
ln(22) = 3.09
斜率 = (3.09 − 4.11) / 18 = −0.0567 /min
τ = 1 / 0.0567 ≈ 17.6 分钟
```

意思是：每 17.6 分钟，温差缩小到原来的 1/e ≈ 37%。

## 坑

- 冰箱温度本身在波动（压缩机启停），所以环境温度要实测，不要用标称值。
- 开冰箱门会引入大幅扰动，忍住别开。
- 杯口敞开和加盖差别很大，两种都试才好玩。
- 水温越高，散热越快（对流和辐射都变强），所以低温段曲线会偏平。
- 记录仪采样间隔别太长，1 分钟够。

## 想再往前一步

## 安全

水温别超过 70°C。玻璃杯骤冷可能裂，用耐热杯。
