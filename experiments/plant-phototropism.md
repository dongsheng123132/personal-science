# 植物向光性延时

> 鞋盒开个洞，看植物怎么"找"到光。

| | |
|---|---|
| **需要** | 一盆小植物或一把豆芽、鞋盒、美工刀、手机（延时摄影） |
| **时间** | 3–5 天 |
| **花费** | ¥10 |
| **难度** | ★☆☆ |
| **验收** | 延时视频里能看到茎明显朝洞口方向弯曲 |

## 为什么值得做

植物没有眼睛，但会朝光长。这个过程叫向光性，是生长素分布不均造成的——背光侧细胞拉得长，植物就弯过去了。

**你可以在 3 天里亲眼看见"生长"这个平时看不见的过程。** 延时摄影把它压缩成 10 秒。

## 怎么做

1. 鞋盒侧面靠近底部开一个 **1 cm 的圆孔**，其他缝隙用胶带封住（只留这一个光源）。
2. 把植物/豆芽放在盒底，离孔 10–15 cm。
3. 手机架在三脚架或书堆上，镜头对准孔径方向，开延时摄影（每 10 分钟拍一张，或手机自带的延时模式）。
4. 让盒子对着窗户或台灯（光从孔进来）。
5. 拍 3–5 天，期间只加水，不要移动。
6. 回放，看茎的弯曲过程。

## 会看到什么

第一天几乎不动，第二到第三天开始明显朝孔弯曲。豆芽长得快，2 天就有肉眼可见的变化。

## 坑

- **手机不能动**。碰一下，后面全部错位。
- 电池和存储要够：3 天每 10 分钟一张 ≈ 430 张。
- 光别太强，尤其别让盒子在烈日下暴晒，会烤死。
- 植物别贴着孔，留出弯曲的空间。
- 黑暗里拍不了照，所以要在盒内补一点柔光，或者把延时拍摄放在白天进行（隔一段时间开盒拍一张，会抖动，不推荐）。

## 想再往前一步

- 做对照：一盆孔在左，一盆孔在右，看弯曲方向。
- 转 180° 盒子的孔，看植物会不会"掉头"——转向需要多久？
- 用红色和蓝色 LED 各照一盆，比较向光性强度。

## 安全

无。
