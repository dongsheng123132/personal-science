# 影子测地球半径

> 和不同纬度的人同一天量影子，还原 2200 年前的方法。

| | |
|---|---|
| **需要** | 一根直杆（晾衣杆、扫把柄）、卷尺、水平地面、**一个住在不同纬度的朋友或网友** |
| **时间** | 约 2 天（主要是约人） |
| **花费** | ¥0 |
| **难度** | ★★☆ |
| **验收** | 算出地球半径在 5000–8000 km 之间 |

## 为什么值得做

公元前 240 年，埃拉托色尼只用了一根杆子和两个城市的距离，就算出了地球的周长。他的方法今天完全可以用：**同一天正午，不同纬度的地方，杆影长度不一样。**

这也是这个清单里少数**必须两个人**才能做的实验。一个人测不出来——这正是它有意思的地方。

## 怎么做

1. 找一个纬度和你差 **≥5°**（约 550 km）的人。越大越好，但要在同一天。
2. 约好**同一天**，各自在**当地正午**（太阳最高的那一刻，不是 12:00）量：
   - 杆高 `h`
   - 影子长度 `L`
3. 各自算太阳天顶角 `θ = arctan(L/h)`。
4. 两人相减得 `Δθ`（换成弧度）。
5. 查两地之间的**大圆距离** `s`（地图工具都能算，注意取南北方向为主的距离）。
6. 算 `R = s / Δθ`。

## 算一下

埃拉托色尼的经典数据：亚历山大港正午杆影角 7.2°，赛伊尼（今阿斯旺）正午没有影子（θ=0），两地距离约 800 km。

```
Δθ = 7.2° = 0.1257 rad
R = 800 / 0.1257 ≈ 6366 km
```

真实值 6371 km。他差不到 1%。

## 坑

- **"正午"是当地太阳最高点**，不是钟表 12 点。用"最短影子"来判断更靠谱：提前半小时开始，每 2 分钟量一次，找最小值。
- 杆子必须垂直、地面必须水平。用水平仪或倒水看。
- 纬度差太小（<3°），误差会放大到无法用。
- 距离要用大圆距离；如果两地主要是东西向，这个方法不成立。
- 大气折射会让太阳看起来偏高一点，产生约 0.5° 的系统误差——业余条件下接受它。

## 想再往前一步

- 三个人、三个纬度做一次，看结果一致性。
- 换成测**地球自转**：同一天同一经度、不同纬度，看正午时刻差。
- 用同一根杆子记录一个月的正午影长，画出"8 字形"（日行迹）——那就是地球轨道的形状证据。

## 安全

无。别直视太阳，别用望远镜看太阳。
