# 两块钱测电池内阻

> 一块万用表加一个电阻，量出电池的"内耗"。

| | |
|---|---|
| **需要** | 万用表、一个 10Ω 5W 功率电阻、电池和电池盒（建议碱性 AA） |
| **时间** | 20 分钟 |
| **花费** | ¥10 |
| **难度** | ★☆☆ |
| **验收** | 新碱性电池 < 0.5Ω，旧电池明显更高（通常 2 倍以上） |

## 为什么值得做

电池不是理想电压源。它有内阻，电流一大，电压就掉——这就是旧电池带不动电机、手机冬天突然关机的原因之一。

内阻没法直接测，但可以用"开路电压减带载电压"算出来。原理只有一行：

```
I = V₁ / R
r = (V₀ − V₁) / I
```

## 怎么做

1. **测开路电压 V₀**：不接任何负载，直接量电池两端。
2. **接上电阻 R**，立刻测电阻两端的电压 V₁。要快——电压会慢慢恢复。
3. 算 `I = V₁ / 10`，再算 `r = (V₀ − V₁) / I`。
4. 换一节新电池、一节旧电池、一节镍氢，各测一遍。
5. 每节重复 3 次，取平均。

## 算一下

新碱性 AA：

```
V₀ = 1.60 V
V₁ = 1.55 V（10Ω 负载）
I  = 0.155 A
r  = 0.05 / 0.155 ≈ 0.32 Ω
```

旧电池可能 `V₀ = 1.45`、`V₁ = 1.20`，算出来 `r ≈ 2Ω`。

## 坑

- 压差可能只有 20–50mV，**用 mV 档**，不然全是噪声。
- 电阻会发热，测完别用手捏。
- 电池电压在负载后会恢复，所以 V₁ 越"立刻"越好。或者接了负载等 5 秒读稳定值，两种方法别混用。
- 不同类型电池内阻差别很大：碱性 0.1–0.3Ω、镍氢更低、锂电几欧到几十毫欧。
- **不要测汽车电瓶、大容量锂电组**，电流会很大，危险。

## 想再往前一步

- 用两个不同阻值的电阻各测一次，解出更准的内阻（消除接触电阻影响）。
- 测同一节电池连续放电过程中的内阻变化。
- 测温度影响：冰箱里冻一下再测。

## 安全

不要短路电池。功率电阻会烫手，放隔热垫上。只测小电池。
