# 偏振：一块胶带 + 两块屏幕

> 用手机屏幕和透明胶带，看见塑料里的应力。

| | |
|---|---|
| **需要** | 一块手机屏幕（当光源）、透明胶带、偏振太阳镜或第二块手机屏幕（当检偏器）、透明塑料尺/塑料盒 |
| **时间** | 20 分钟 |
| **花费** | ¥0–20 |
| **难度** | ★☆☆ |
| **验收** | 转动检偏器时，能看到明显的明暗变化或彩虹色 |

## 为什么值得做

光是有"朝向"的，肉眼看不见，但偏振片能。透明胶带、塑料尺这类东西会把偏振方向转一个角度（双折射），再透过第二片偏振片看，就会出现颜色。

这个效应不是玩具——**工程上就是用它在透明塑料件里找应力**：塑料受力后双折射会变强，颜色会跟着变。

## 怎么做

### 基础版：看见偏振

1. 手机打开一张纯白图片，亮度拉满。
2. 戴上偏振太阳镜，转动头部 / 转动手机，屏幕会周期性地变暗变亮。
3. 找到最暗的角度——这时你"看见了"偏振。

### 进阶版：看见应力

1. 手机屏幕保持纯白，把透明胶带一条条平行贴在屏幕上。
2. 透过偏振太阳镜看（或者用第二块手机的屏幕当检偏器，两块屏叠加）。
3. 转动偏振片角度，胶带会出现**彩色条纹**，角度不同颜色不同。
4. 换成透明塑料尺：先看，再把尺子轻轻掰弯，颜色会变化——那就是应力。

## 会看到什么

- 胶带层数不同，颜色不同（每层旋转的相位不一样）。
- 转检偏器 90°，颜色会反转。
- 弯折塑料的地方会亮起来，颜色条带更密。

## 坑

- 不是所有手机屏都能当偏振片。LCD 屏前面有偏振片，OLED 屏结构不同，可能不理想。
- 环境光太亮会盖掉效果，拉上窗帘。
- 胶带要贴平、不要叠出气泡。
- 偏振太阳镜的轴向不同，戴着看和取下来看效果不一样。

## 想再往前一步

- 用两片偏振片 + 塑料件搭一个"应力检测台"，拍下不同受力状态的对比图。
- 拍一张透明尺弯曲过程的连拍，看颜色怎么变——这就是光弹性实验的业余版。
- 用手机摄像头看 LCD 屏：旋转手机，屏幕在摄像头里会闪/变暗（摄像头本身也有偏振特性）。
