# 种子发芽率对照

> 每组 20 颗，验证"光照到底影不影响发芽"。

| | |
|---|---|
| **需要** | 同一批种子（绿豆最好买，生菜种子适合做对照）、纸巾、两个浅盘、水、纸盒（遮光用） |
| **时间** | 5 天（每天看一次，每次 2 分钟） |
| **花费** | ¥10 |
| **难度** | ★☆☆ |
| **验收** | 两组各 20 颗以上，第 5 天算出两组发芽率 |

## 为什么值得做

这是最便宜的"对照实验"训练：一个变量（光），其他全一样，每组样本够多，结果用百分比说话。

而且结果可能反直觉：**很多种子在黑暗里发芽更好**（比如绿豆），有些反而必须见光（比如生菜）。你自己测出来的答案，比课本上的可靠。

## 怎么做

1. 每组 **≥20 颗**，随机分（不要挑大的）。
2. 两个盘子各铺两层纸巾，摆上种子，加同样多的水（纸巾湿但不积水）。
3. A 组放窗台（有光），B 组用纸盒扣住（完全遮光），**两者温度尽量一致**。
4. 每天固定时间数发芽数。**发芽标准提前定死**：比如芽长 ≥ 2mm 才算。
5. 第 5 天算发芽率：
   ```
   发芽率 = 发芽数 / 总种子数 × 100%
   ```
6. 两种种子各做一遍：绿豆（嫌光）和生菜（需光）。

## 会看到什么

典型结果可能是：绿豆 A 组 55%、B 组 85%；生菜反过来 A 组 90%、B 组 20%。
**两个反方向的结果，比一个"验证成功"更有意思。**

## 坑

- 每组少于 20 颗，百分比波动太大，结论没意义。50 颗更好。
- 水要一致。一边湿一边干，你就变成在测含水量了。
- 温度也要一致。窗台白天会晒热——把 B 组放在同一个窗台旁边，只是扣上盒子。
- 判定标准事后改 = 作弊。做之前写死。
- 霉变会让结果作废，湿度过大时每天检查。

## 想再往前一步

- 加第三组：红光/蓝光 LED 下（植物的光受体对波长有偏好）。
- 测发芽**速度**而不只是最终比例：画"累计发芽数"曲线。
- 换不同年份的种子，看发芽率随时间下降多少。

## 安全

无。别吃实验用的种子（可能拌过药）。
