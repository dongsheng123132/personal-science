# 实验名

> 一句话说清楚：你能亲手验证什么。

| | |
|---|---|
| **需要** | 列出每一样东西，别写"简单器材" |
| **时间** | 大概多久（含等待时间） |
| **花费** | ¥多少（写出最贵的那个） |
| **难度** | ★☆☆ / ★★☆ / ★★★ |
| **验收** | 做之前就要能写死：算出多少算成功 |

## 为什么值得做

两三句。别吹，说清楚这个实验在验证什么、为什么好玩。

## 怎么做

1. 第一步
2. 第二步
3. ……

## 算一下 / 会看到什么

把公式和典型数值写出来，让人做完能自己判断对不对。

## 坑

- 最容易错的地方
- 误差从哪来
- 什么情况会得出错误结论

## 想再往前一步

- 换条件再测一次
- 换个方法测同一个量
- 和网上别人的结果比

## 安全

一句话。没有危险就写"无"。
