# 实验名

> 一句话说清楚：你能亲手验证什么。

| | |
|---|---|
| **需要** | 列出每一样东西，别写"简单器材" |
| **时间** | 大概多久（含等待时间） |
| **花费** | ¥多少（写出最贵的那个） |
| **难度** | ★☆☆ / ★★☆ / ★★★ |
| **验收** | 做之前就要能写死：算出多少算成功 |

## 为什么值得做

两三句。别吹，说清楚这个实验在验证什么、为什么好玩。

## 怎么做

1. 第一步
2. 第二步
3. ……

## AI 可以怎么帮你

**这一节不能省。** 写清楚 AI 在这个实验里具体做什么，最好给能直接复制的 prompt。

- **先算参数**：让它算量程、距离、次数，别做完才发现测不出来
- **写分析脚本**：拍的照片/视频/表格，让它写 Python 把数据提出来
- **拟合与作图**：把数据丢给它，算拟合优度、画曲线
- **抓错**：把步骤贴给它，让它扮演审稿人找漏洞
- **升级硬件**：ESP32 / 手机 / 开源硬件能替代哪台昂贵仪器

## 算一下 / 会看到什么

把公式和典型数值写出来，让人做完能自己判断对不对。

## 坑

- 最容易错的地方
- 误差从哪来
- 什么情况会得出错误结论

## 想再往前一步

- 换条件再测一次
- 换个方法测同一个量
- 和网上别人的结果比

## 安全

一句话。没有危险就写"无"。
