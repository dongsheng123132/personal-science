# 牛顿棱镜：把白光拆成彩虹

> 一束阳光穿过三棱镜，墙上出现一条彩虹。白光不是白的——它是很多颜色的叠加。

| | |
|---|---|
| **需要** | 玻璃三棱镜（¥10–30）、阳光或白光 LED、白纸当屏幕、量角器/手机 |
| **时间** | 30 分钟 |
| **花费** | ¥10–30 |
| **难度** | ★☆☆ |
| **验收** | 光谱里能分辨出至少 5 个连续色带；红色比蓝色的偏折角至少小 2° |

## 为什么值得做

1666 年，牛顿让一束阳光穿过棱镜，第一次证明"白光由各种颜色组成，而且颜色不能再被分开"。

这是"光的颜色到底是什么"这个问题的第一个正确答案，也是你第一个能亲手做出来的"光谱仪"。

## 怎么做

1. 让一束窄光射进来：阳光从窗帘缝、或用手电筒+纸板开一条 3mm 的缝。
2. 光穿过三棱镜（顶角朝上，让光斜着入射一个面）。
3. 对面白纸当屏，转动棱镜，直到纸上出现清晰的彩虹。
4. 观察颜色顺序：红橙黄绿蓝紫。红色偏折最小、紫色最大。
5. 量：在纸上记下红光和紫光的位置，量它们到"无棱镜时光点位置"的距离，反推两个颜色的偏折角差。
6. 手机拍照，旁边放尺子当比例尺。

## 为什么颜色会被分开

玻璃对不同颜色的光折射率不同（色散），紫光折射率更大，所以弯得更厉害：

```
n(紫) > n(红) → 紫光偏折角更大
```

白光是多种波长叠加，一进棱镜就各自走各自的，出来就摊开了。

## AI 可以怎么帮你

- **算偏折角**：
  `棱镜顶角 60°、玻璃折射率红 1.51、紫 1.53，入射角 40°，帮我算红光和紫光出射角各是多少，差几度。`
- **从照片标颜色**：
  `这是我拍的光谱照片（附尺子）。写一段 Python，沿光谱方向采样 RGB，标出红/绿/蓝三段的像素位置，换算成角度。`
- **验证"颜色不可再分"**：
  `牛顿说单个颜色不能再被棱镜分开。我没法用第二块棱镜，能用什么办法在家里近似验证？`
- **解释为什么天空是蓝的**：
  `这个实验和'天空为什么是蓝的'有同一个物理量在起作用——瑞利散射和色散差在哪？`

## 坑

- 光要**窄**，缝太宽颜色会叠成一片白。
- 环境光太亮会把光谱冲淡，拉窗帘。
- 棱镜顶角朝上、斜面朝向光源，角度不对就看不到。
- 阳光是免费的但会动，用白光 LED 手电更稳，缺点是没有阳光那么强的连续谱细节。

## 想再往前一步

- 量红光/紫光偏折角差，和"棱镜色散表"对比。
- 换成不同液体（水、盐水、糖水）做"液体棱镜"，看色散变化。
- 把光谱拍下来和手机屏幕的自发光光谱对比（LED 光谱有峰，不是连续谱）。

## 安全

阳光/白光 LED，别用激光直射眼睛。
