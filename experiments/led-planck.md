# LED 估普朗克常数

> 不同颜色的 LED，点亮电压不一样。差值里藏着一个常数。

| | |
|---|---|
| **需要** | 万用表、10kΩ 多圈电位器、5 种不同颜色的 LED（红/黄/绿/蓝/紫）、电池盒（3–5V）、面包板或直接焊 |
| **时间** | 1 小时 |
| **花费** | ¥30 |
| **难度** | ★★★ |
| **验收** | 算出 3×10⁻³⁴ 到 9×10⁻³⁴ 之间的数，且电压随波长单调变化 |

## 为什么值得做

LED 发光的条件是：电子跨过半导体带隙，放出一个光子。光子能量 `E = hc/λ`，而带隙近似等于点亮电压乘电子电荷 `E ≈ eV`。

所以：**波长越短，需要点亮的电压越高**。把 5 个点测出来画一条线，斜率就能反推普朗克常数。

这是少数几个**用几十块钱在家测出量子力学常数**的实验。

## 这件事为什么重要

**当年**：1900 年普朗克提出能量量子；1905 年爱因斯坦用光量子解释光电效应；1962 年霍尔尼雅克做出第一只实用 LED。

**现在**：几十块钱的 LED 就能把普朗克常数测到同一量级——这是量子力学最平民化的入口。

**对后来的影响**：半导体带隙工程后来长出激光、太阳能电池和整个 LED 照明产业。

**AI 时代还能做什么**：线性拟合、误差传播、再和 CODATA 推荐值对比，看看你差在哪。

## 怎么做

1. 查（或估）每种 LED 的峰值波长：红 630nm、黄 590nm、绿 525nm、蓝 470nm、紫 405nm。买的时候商品页一般有。
2. 接电路：电池 → 多圈电位器 → LED → 回电池。万用表**电压档**跨在 LED 两端。
3. 在**暗室**里，从 0 开始慢慢调电位器升压。眼睛贴近 LED（别直射），记下"刚能看出一点光"时的电压。
4. 每种颜色做 3 次，取平均。
5. 画 `V` 对 `1/λ` 的图，拟合斜率 `k`，则

```
h = k × e / c
```

其中 `e = 1.602×10⁻¹⁹ C`，`c = 3×10⁸ m/s`。

## 算一下

典型数据：

| 颜色 | λ (nm) | V_on (V) |
|---|---|---|
| 红 | 630 | 1.8 |
| 黄 | 590 | 1.9 |
| 绿 | 525 | 2.2 |
| 蓝 | 470 | 2.7 |
| 紫 | 405 | 3.0 |

斜率约 `1.4×10⁻⁶ V·m`，算出来 `h ≈ 7×10⁻³⁴ J·s`（真值 6.63×10⁻³⁴）。数量级对就算成功。

## 坑

- "刚发光"是主观判断。固定暗室、固定距离、同一双眼睛，三次取平均。
- 白光 LED 不能用，它是蓝光芯片加荧光粉。
- 万用表的输入阻抗会把微小电流分走，读数偏低。
- 电位器要能细调，普通单圈电位器跳得太粗。
- 实际点亮电压还包含串联电阻和理想因子的影响，所以这注定是个"估算"，不是精确测量。

## 想再往前一步

- 用示波器或单片机采 I-V 曲线，找拐点，比"肉眼判定"客观。
- 同一个颜色的不同厂家 LED 对比，看差多少。
- 反过来：如果你信 `h`，可以用这个方法估未知 LED 的波长。

## 安全

电压 ≤ 5V，安全。不要直视 LED，尤其是紫光和蓝光。
