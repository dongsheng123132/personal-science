# AI 设计的实验方案（草稿）

这里放 `collector/design.py` 每天自动生成的**实验页草稿**，每个文件开头都标了：

```
<!-- 草稿：AI 生成，未经人工核对。原文：... -->
<!-- 待核实：型号、价格、参数请对照原文确认后再进 experiments/ -->
```

## 它和 `experiments/` 的区别

| | `inbox/designs/` | `experiments/` |
|---|---|---|
| 谁写的 | AI | 人（可以拿草稿改） |
| 状态 | 草稿，未核对 | 发布，进清单 |
| 可以错 | 可以——所以标了"未核对" | 不行，验收标准必须一次写死 |

## 怎么把一个草稿变成正式实验页

1. 打开草稿，对照它引用的原文链接核一遍：**型号、价格、参数、公式**
2. 删掉不靠谱的部分，补上你实际做过的坑
3. 存成 `experiments/<英文小写连字符>.md`
4. 在 [README](../../README.md) 的清单表里加一行
5. 提 PR

**核对这一步不能省。** AI 写方案很快，但它不知道你家厨房的微波炉转盘能不能拆。

## 为什么保留草稿而不是直接发布

因为清单里每一页都要能"照着做"。草稿是半成品，发布出去会浪费别人的时间。

草稿公开在这里，是给下一个写页的人省时间，不是给读者直接用的。
