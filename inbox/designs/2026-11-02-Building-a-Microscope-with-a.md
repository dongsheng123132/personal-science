# 自制立体视角显微镜（重做版）
> 用一部手机 + 一块凸透镜 + 一个斜置支架，验证：斜看样品时，能同时看清焊点顶部和侧面，且放大倍率可算、可测。

| | |
|---|---|
| **需要** | 智能手机（任意能拍照的，型号不限）；凸透镜 1 片（焦距 20–50 mm，直径 ≥ 15 mm，可从旧放大镜/激光笔/玩具拆，或网购"待核实"具体型号）；硬纸板或木条；橡皮筋/胶带；小螺丝或细铜丝（做样品）；直尺；白纸；台灯（可调角度） |
| **时间** | 2–3 小时（含调试） |
| **花费** | ¥0–50（透镜若需购买，价格"待核实"；其余家中现成） |
| **难度** | ★★☆ |
| **验收** | ① 手机屏幕上能同时看到样品的**顶面**和**至少一个侧面**（斜视角度 ≥ 30°）；② 用直尺在白纸上标定，算出放大倍率 M，实测 M 在 **3–15 倍**之间；③ 同一焊点/螺丝，斜视下能分辨出顶部与侧面的分界线（肉眼可辨）。三条全满足算成功。 |

## 为什么值得做

普通俯视显微镜只能看正上方，焊点、螺丝、元件侧壁全被挡住。斜置样品 + 单透镜 + 手机，等于一个"能歪头看"的低倍立体镜。原理简单：透镜成像 + 视角倾斜，不需要双目镜、不需要专业光学台。做完你能亲手验证"斜视放大"这件事，而不是背公式。

## 怎么做

1. **做支架**：把透镜用橡皮筋固定在硬纸板/木条一端，手机摄像头对准透镜中心，距离调到能对焦（约等于透镜焦距，20–50 mm 那片就试 20–50 mm）。
2. **固定样品**：把小螺丝/细铜丝粘在另一块纸板上，纸板**斜放**（与水平面成 30–60°），放在透镜下方 1–3 cm 处。
3. **打光**：台灯从侧面 45° 照样品，避免正上方直射（会反光糊成一片）。
4. **对焦**：手机开拍照，前后微调手机-透镜距离，直到样品边缘清晰。
5. **拍/看**：调样品倾斜角，直到屏幕里同时出现顶面和侧面。
6. **标定倍率**：白纸上画 1 mm 间隔的刻度线，放同样位置拍一张，数屏幕上 1 mm 对应多少像素；再拍样品，用像素比算 M。

## AI 可以怎么帮你

- **算倍率**：把"透镜焦距 f=__ mm，物距 u=__ mm，像距 v=__ mm"发给 AI，让它用 1/f = 1/u + 1/v 和 M = v/u 算理论倍率，并和你的实测对比。
  > prompt：`凸透镜焦距 f=30mm，物距 u=25mm，请用薄透镜公式算像距 v 和放大倍率 M，并说明这是实像还是虚像。`
- **排查对焦失败**：描述现象让 AI 给排查顺序。
  > prompt：`手机透过凸透镜拍照，画面一直模糊，可能原因有哪些？按最可能到最不可能排序，每条给一个 1 分钟内能做的检查动作。`
- **设计标定方法**：让 AI 给一个不依赖专业工具的倍率标定方案。
  > prompt：`我只有直尺和白纸，怎么标定手机+凸透镜的放大倍率？给一个 5 步以内、每步可操作的方法。`
- **解释斜视几何**：让 AI 画/描述倾斜角与可见侧面的关系。
  > prompt：`样品倾斜 45°，透镜在正上方，为什么能看到侧面？用简单几何解释，并说明倾斜角多大时侧面开始可见。`
- **写记录表**：让 AI 生成一张实验记录表模板（倾斜角、物距、倍率、清晰度打分）。
  > prompt：`帮我做一张显微镜实验记录表，列：倾斜角、物距、实测倍率、顶面清晰度(1-5)、侧面可见(是/否)，用 Markdown 表格。`

## 算一下 / 会看到什么

- 薄透镜：1/f = 1/u + 1/v，M = v/u。f=30 mm、u=25 mm 时，v=150 mm，M=6 倍（理论值，实测会偏小，因为手机镜头还有自己的焦距）。
- 验收倍率 3–15 倍是保守区间：太低看不清细节，太高景深太浅、手一抖就糊。
- 倾斜 30° 时侧面开始露出来；45–60° 最明显，但超过 60° 顶面会变形。
- 会看到：样品边缘有轻微色边（单透镜色差，正常）；景深浅，只有一条窄带清晰。

## 坑

1. **正上方打光** → 反光糊成白块。必须侧光 45°。
2. **手机-透镜距离没对** → 永远模糊。先单独用透镜对白纸上的字对焦，找到清晰距离再装手机。
3. **样品太厚** → 侧面被自身挡住。用薄样品（螺丝头、细铜丝、扁平焊点）。
4. **手抖** → 倍率越高越抖。把手机和支架都压住，或用延时拍照。
5. **以为倍率越高越好** → 超过 15 倍景深只剩零点几毫米，反而看不清侧面。先保 3–8 倍。

## 想再往前一步

- 换两片透镜做"双目"：左右各一片，间距约等于瞳距，看能不能出立体感（难度升到 ★★★）。
- 加一个可调倾角台（纸板 + 量角器），把"倾斜角 vs 侧面可见度"做成曲线。
- 用 AI 帮你把拍到的图做边缘增强，对比增强前后焊点分界线的可辨度。

## 安全

- 台灯别用裸灯泡直射眼睛；透镜别对着太阳聚光（会烧纸、伤眼）。
- 拆旧放大镜/激光笔时小心镜片碎边，戴手套或用布包着拆。
- 手机固定牢，别在桌边悬空，防跌落。
- 全程无电、无高温、无化学品，一个人在家可做。
