# 低温下电池还能撑多久？——自己测一次

> 把一节普通碱性电池放进冰箱冷冻室，测它在 0 °C 附近还能放出多少电，再和室温对比。

| | |
|---|---|
| **需要** | 碱性电池 1 节（AA 或 AAA，型号不限，普通品牌即可）；数字万用表 1 台（能测直流电压和电流，型号待核实，¥30–80 档）；小灯泡或 LED + 限流电阻（LED 需串联约 220 Ω 电阻，待核实）；冰箱冷冻室；温度计（能测 0 °C 以下，家用冰箱温度计即可）；导线、鳄鱼夹若干；秒表（手机即可） |
| **时间** | 一个下午 + 冷冻 2 小时 |
| **花费** | ¥50–120（万用表占大头，若已有则接近 ¥0） |
| **难度** | ★★☆ |
| **验收** | 冷冻 2 小时后的电池，在 0 °C 附近测得的放电电流（或点亮 LED 的持续时间）**不低于室温对照组的 50%**；且冷冻后电压不低于 1.0 V。两个条件同时满足算成功。 |

## 为什么值得做

电池怕冷，这是常识。但"怕冷"到底是多少？是电压掉了，还是内阻涨了？你可以在家把这件事拆开看：同一节电池，室温测一次，冷冻后测一次，看哪个量变了、变了多少。

Hackaday 那篇讲的是 NASA 在搞耐极端温度的电池电解质。你复现不了 NASA 的配方，但你能亲手摸到"温度—电池性能"这条曲线的低端。做完你会对"冬天手机掉电快"有具体数字，而不是一句感觉。

## 怎么做

1. **先定对照组。** 室温（记下温度，比如 22 °C）下，把电池、LED + 220 Ω 电阻、万用表串成回路，测电流。记下读数。同时测电池空载电压。
2. **冷冻。** 电池单独放进冷冻室，2 小时。温度计一起放，确认冷冻室实际温度（家用冷冻室通常 −18 °C 左右，待核实你家的）。
3. **快速取出测量。** 取出后 30 秒内接回同一回路，测电流和电压。动作要快，电池回温很快。
4. **记录回温过程。** 之后每 2 分钟测一次电流，测 10 分钟。你会看到电流慢慢爬回室温值。
5. **画表。** 横轴时间，纵轴电流。冷冻那一刻是谷底。

注意：LED 回路里电流受电阻限制，测的是"电池在负载下能推多少电流"，间接反映内阻变化。想更直接，可以用万用表电阻档粗测电池内阻（方法待核实，简易法误差大，只做趋势参考）。

## 算一下 / 会看到什么

- 室温组电流记为 I_room，冷冻组记为 I_cold。
- 验收看 **I_cold / I_room ≥ 0.5**。
- 典型预期：碱性电池在 0 °C 附近容量和电流都会降，降幅随温度走。−18 °C 下可能只剩室温的三到五成（具体因品牌和批次而异，待核实，你的数据就是你的答案）。
- 回温曲线：前 2–3 分钟爬得最快，之后变缓。如果 10 分钟还没回到 80%，检查是不是电池没取出来放太久、或者回路接触不良。

## 坑

- **取出后测太慢。** 电池回温以分钟计，磨蹭 2 分钟数据就废了。提前把回路搭好，取出即插。
- **冷凝水。** 冷冻电池取出后表面结露，可能短路或接触不良。擦干再测，或套个塑料袋只露电极。
- **不同电池不能比。** 对照组和冷冻组必须是**同一节**电池，先室温测、再冷冻测。换电池等于换变量。
- **LED 正向压降吃掉差异。** LED 有阈值电压，电池电压稍降可能 LED 直接不亮，电流读数变成 0，看起来像"完全失效"，其实只是没过阈值。用电阻负载（比如 100 Ω）测电流更线性。
- **万用表档位。** 测电流要串进回路，别并联在电池两端（会短路）。测电压才并联。
- **冷冻室温度不是恒定 0 °C。** 你家冷冻室可能是 −18 °C，写报告时写实测温度，别写"0 °C"。

## 想再往前一步

- 换锂电池（CR2032 或 18650，注意 18650 别短路）做同样测试，对比曲线。
- 做 4 个温度点：室温、冷藏（约 4 °C）、冷冻（约 −18 °C）、冰盐浴（约 −10 °C，需另配，待核实可行性）。
- 测"冷冻后能点亮 LED 多久"，而不只是瞬时电流，得到持续时间对比。

## 安全

- 碱性电池冷冻一般安全，但**不要冷冻已鼓包、漏液或过放的电池**。
- 不要给电池加热来"加速回温"，尤其不要用明火或微波炉。
- 18650 等锂电不做冷冻实验，除非你清楚风险；本实验默认用碱性电池。
- 冷凝水 + 电器 = 短路风险，测量前擦干。
- 冷冻室取放注意别烫伤（低温冻伤），戴手套。
