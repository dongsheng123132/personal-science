# 汤姆森阴极射线实验：在家测电子的荷质比

> 用一根旧显像管或自制放电管，亲手测出阴极射线粒子的 e/m，看它是否落在 10¹¹ C/kg 量级。

| | |

## 为什么值得做

1897 年汤姆森用阴极射线管证明：射线是带负电的粒子，且其荷质比比氢离子大约 1000 倍。这是人类第一次"看见"亚原子粒子。

今天你在家能重做的核心，不是复刻他的玻璃管，而是复刻他的**测量逻辑**：让带电粒子在电场和磁场中偏转，从偏转量反推 e/m。这个逻辑后来长成了质谱仪、电子显微镜、CRT 本身。

它值得做，因为：结果是一个**数字**，不是"看起来亮了"。数字对不上，就是哪里错了。

## 怎么做

**思路**：阴极射线（电子）在均匀磁场中做圆周运动，在均匀电场中做抛物线偏转。测出偏转量，联立求 e/m。

1. **准备射线源。** 拆一台旧 CRT，取出电子枪和高压部分；或自制低压放电管（管内抽到约 10⁻² Torr，待核实抽气手段）。**先读安全节。**
2. **加磁场。** 在管外放两块钕磁铁，形成近似均匀横向磁场 B。用霍尔探头或"待核实"的简易法测 B；没有探头就用已知电流的线圈估算，误差记下来。
3. **观察偏转。** 通电，看射线斑点在磁场下偏移成圆弧。用刻度尺量斑点位移 y 和到偏转区的距离 L。
4. **加电场。** 在两块平行铝板间加电压 U，板间距 d，量电场偏转量。
5. **记录。** 每次记：U、d、B、y、L。至少 3 组不同 U。
6. **算 e/m。** 见下一节公式。
7. **对照验收标准。** 落在区间内算成功；不在，先查 B 和 d 的测量误差。

## 算一下 / 会看到什么

磁场偏转（圆周运动）：

$$r = \frac{mv}{eB}, \quad \frac{e}{m} = \frac{v}{Br}$$

电场偏转（抛物线）：

$$y = \frac{eE L^2}{2mv^2}, \quad \frac{e}{m} = \frac{2y v^2}{E L^2}$$

两式联立消去 v，即可只用可测量求 e/m。

**会看到**：射线斑点在磁铁靠近时明显偏移，换磁极方向偏移反向；加电场时同样偏移、反向。偏移量随 U 增大而增大。

**验收对照**：算出的 e/m 在 0.5–2.5×10¹¹ C/kg 之间，3 次重复离散 < 30%。

## 坑

- **B 测不准。** 钕磁铁表面磁场不均匀，用"标称值"会错一个量级。这是最常见的失败点。
- **d 量错。** 平行板不平行、边缘效应，实际有效 d 和尺子量的小有差别。
- **真空度不够。** 自制放电管抽不干净，射线散、斑点糊，偏转量读不准。
- **高压打火。** 电极间距太小或绝缘不够，会放电，读数乱跳。
- **把荧光屏余辉当成斑点。** 关电后屏还亮，误读位置。
- **只做一次。** 单次数据无法判断离散度，验收标准就失效了。

## 想再往前一步

- 用已知 e/m 反推磁铁实际 B，和霍尔探头对照，校准你的磁场测量。
- 换不同气体（待核实可行气体），看放电颜色和偏转是否变化。
- 复刻汤姆森 1913 年的阳极射线实验思路，用类似装置看正离子偏转——这是质谱法的起点。

## 安全

- **CRT 拆机有致命高压。** 显像管和高压包断电后仍可能存电，必须放电、验电后再碰。没把握就不要拆，改用成品低压放电管。
- **高压电源全程绝缘。** 戴绝缘手套、护目镜，单手操作，另一只手不碰金属。
- **钕磁铁夹手。** 两块磁铁吸合力量大，别让手指夹在中间。
- **放电管可能炸裂。** 加防护罩，人不要正对管身。
- **不涉及放射性、不涉及危险化学品。** 若你想到用放射性源或强酸，停，这超出本实验范围。
- 任何一步不确定，先停，问 AI 或查资料，别硬上。
