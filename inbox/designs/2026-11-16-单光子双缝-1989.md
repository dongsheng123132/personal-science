# 单光子双缝（1989）：用“逐次累积”亲手验证“一个光子只打一个点”

> 你没法在家做真单光子实验，但你能亲手复现它的**统计核心**：单次事件是随机的点，累积起来才出现干涉条纹。

## 为什么值得做

单光子双缝是量子力学最反直觉的一张图：**一次只发一个光子，它却像同时走了两条缝**。1989 年那批实验（Aspect 等人，具体文献待核实）把它拍成了“逐次累积”的影像——先是散点，后来条纹自己长出来。

真机做不了：单光子源、暗室、单光子探测器，价格远超预算，还需要资质。但这件事的**要害是统计**，不是硬件。你用随机数模拟“单个光子落点”，亲手看条纹从噪声里长出来，就抓住了这个实验 90% 的认知价值。剩下 10%（它真的是量子、不是经典波）只能靠读原始论文补，本页会告诉你怎么读。

## 怎么做

1. **先写死验收标准**。把上面表格里那三条抄到纸上或文件里，做完对照。别做完再改标准。
2. **装环境**。装 Python 3，然后 `pip install numpy matplotlib`。跑一句 `import numpy; print(numpy.__version__)` 确认能跑。
3. **写“单光子落点”生成器**。核心只有两步：
   - 双缝干涉的**概率密度**：`I(x) ∝ cos²(π d x / (λ L))`（d 缝距、λ 波长、L 屏距，自己设合理值，比如 d=0.1 mm、λ=500 nm、L=1 m，单位统一）。
   - 每次“发一个光子”：按这个密度**随机抽一个 x**，画一个点。**一次只画一个点**。
4. **逐次累积**。循环 N 次（先 20，再 200，再 2000，再 20000），每轮把已有点画在同一张图上。观察：少点时像噪声，多点时条纹浮现。
5. **加“哪条缝”开关**。再写一个版本：随机决定光子“走左缝”或“走右缝”，落点按**单缝**分布抽。累积后画图——条纹没了，只剩两条亮带。这就是“探测路径 → 干涉消失”。
6. **对照验收**。三条逐一打勾。没中就看「坑」。

## 算一下 / 会看到什么

- 条纹间距近似 `Δx ≈ λ L / d`。代入 d=0.1 mm、λ=500 nm、L=1 m：`Δx ≈ 5×10⁻⁷ × 1 / 1×10⁻⁴ = 5×10⁻³ m = 5 mm`。所以横轴取 ±20 mm 左右，能看到约 8 条亮纹。
- **N=20**：点散，看不出规律——正常。
- **N=2000**：条纹开始成形，但仍有毛刺。
- **N=20000**：条纹干净。
- **开“探测路径”**：条纹消失，剩两条宽亮带，中心不再有暗纹。
- 验收对照：①②③ 全中 = 成功。

## 坑

- **把“模拟”说成“做了量子实验”**。这是统计模拟，不是单光子源。结论只到“统计行为像”，不到“光子真是量子”。别越界。
- **一次画一堆点**。必须**逐次**累积，否则你看不到“从噪声到条纹”的过程，等于白做。
- **参数单位不统一**。d 用 mm、λ 用 nm、L 用 m 混着代，条纹间距会差几个数量级，图看着像失败其实是算错。
- **点数太少就下结论**。200 个点看不出条纹是正常的，别急着改代码。
- **“探测路径”版本写错**。如果两条单缝分布重叠太多，看起来还是像有干涉。先单独画单缝分布确认。
- **验收标准事后改**。做完觉得“差不多”就放宽标准——这是自欺，本页第一条就是防这个。
