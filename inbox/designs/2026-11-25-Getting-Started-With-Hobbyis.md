# 用手机照片做摄影测量 3D 扫描：亲手把一件实物变成可测量的模型

> 你能亲手验证：用手机拍一圈照片，免费软件能重建出尺寸误差在 ±5% 以内的实物模型。

| | |
|---|---|
| **需要** | 智能手机（任意能拍照的，型号不限）；一件哑光、有纹理、不反光的小物件（如马克杯、鞋、玩具，尺寸 10–20 cm）；一张报纸或格子纸（做背景和比例尺）；直尺；免费软件 Meshroom（Windows/Linux，待核实当前版本号）或手机端 RealityScan / Polycam 免费档（待核实免费额度）；一台电脑（Meshroom 需要 NVIDIA 显卡，待核实最低显存要求） |
| **时间** | 一个下午（拍摄 20 分钟 + 重建 1–3 小时 + 测量 20 分钟） |
| **花费** | ¥0–50（只用已有手机和电脑则 ¥0；买一张哑光背景纸约 ¥10–30） |
| **难度** | ★★☆ |
| **验收** | 重建出的模型，用软件量取物件最长边，与直尺实测值相比误差 ≤ 5%；且模型上能看清物件表面至少一处文字或纹理细节 |

## 为什么值得做

摄影测量（photogrammetry）是 3D 扫描里最便宜、最不需要硬件的一条路。原理很老：从多个角度拍同一物体，软件找特征点、算相机位置、三角化出点云。它被考古、测绘、游戏行业用了十几年，今天用手机就能重做。

值得做的理由很实在：你会亲手撞上"照片够不够、光够不够、纹理够不够"这几个真实约束，而不是看视频觉得"哦很简单"。做完你会知道 3D 扫描的瓶颈在哪。

## 怎么做

1. **选物件。** 哑光、表面有花纹或文字、不透明、不反光。别选玻璃杯、白瓷碗、纯色球。物件放在报纸上，报纸的格子/文字同时当纹理和比例尺。
2. **固定光。** 关掉闪光灯。用窗边自然光或一盏台灯，拍摄过程中光源别动。别让物件一半亮一半死黑。
3. **拍第一圈（俯视 30°）。** 绕物件走一圈，每步约 15°，拍 20–30 张。每张和上一张要有 70% 以上重叠。手机别变焦。
4. **拍第二圈（俯视 60°）。** 再绕一圈，同样 20–30 张。
5. **拍顶部。** 从正上方补 5–10 张。
6. **检查。** 翻一遍照片：有没有糊的、有没有曝光突变的、有没有拍到自己的影子挡住物件。糊的删掉重拍。
7. **导入重建。** Meshroom：把照片拖进新工程，点 Start，等。手机端 RealityScan：按 App 引导拍，直接出模型。
8. **测量。** 在软件里量物件最长边（Meshroom 可用 Measure 工具，待核实具体菜单路径；手机 App 一般有测量功能）。和直尺实测值比。
9. **记录。** 写下：照片数、重建耗时、最长边实测值、模型量取值、误差百分比。

## AI 可以怎么帮你

- **帮你定拍摄方案**：`我要用手机摄影测量扫描一个 15 cm 高的哑光马克杯，只有窗边自然光。请给我一份分圈的拍摄清单，写清每圈角度、张数、相机高度，以及怎么判断相邻两张重叠够不够。`
- **帮你读报错**：`Meshroom 重建到 DepthMap 阶段报错，日志最后几行是：【粘贴日志】。请用中文解释这个错误最可能的原因，并按可能性从高到低列出我能自己检查的 3 件事。`
- **帮你算误差、判断是否达标**：`我实测物件最长边 14.8 cm，模型里量出来 15.6 cm。请算误差百分比，判断是否满足 ≤5% 的验收标准，并说明这个偏差更可能来自拍摄、重建还是测量操作。`
- **帮你诊断失败原因**：`我的重建模型表面有大片空洞、边缘发虚。我的拍摄条件是：【光照/照片数/物件材质】。请列出最可能的 3 个原因，每个给一个下次可以改的具体动作。`
- **帮你写记录表**：`帮我做一张 Markdown 表格，列：照片数、光照条件、重建软件、重建耗时、实测最长边、模型最长边、误差百分比、是否达标。留空给我填。`

## 算一下 / 会看到什么

- **重叠率**：一圈 360°，每步 15° → 24 张。相邻两张视角差 15°，重叠通常够。步太大（30° 以上）容易断。
- **误差**：业余条件下，尺寸误差 1%–5% 是常见范围。超过 5% 多半是比例尺没定好或照片太少。
- **会看到**：模型表面有"融化感"、边缘毛糙、背面可能有洞（如果你没拍够背面）。这些都是正常现象，不是你做错了。
- **重建时间**：Meshroom 在普通带独显的电脑上，50–80 张照片大约 1–3 小时（待核实，取决于显卡）。

## 坑

- **反光/透明物件**：玻璃、金属、白瓷几乎必失败。换哑光物件。
- **纯色表面**：软件找不到特征点。靠报纸背景救不了物件本身，换有纹理的物件。
- **光源移动**：拍摄中云遮日、有人走过挡光，重建会错位。固定光、一次拍完。
- **变焦**：手机变焦会改变内参，软件容易算错。全程用主摄，靠走近走远。
- **照片太少或重叠不够**：最典型的失败。宁可多拍，别省。
- **比例尺缺失**：模型没有绝对尺寸，量出来是"任意单位"。必须靠报纸格子或已知尺寸物件定标。
- **Meshroom 显卡门槛**：没有 NVIDIA 显卡可能跑不动（待核实）。先查官方文档再决定。

## 想再往前一步

- 换一个更难的物件（带凹槽、带把手），看误差怎么变。
- 同一物件拍 30 张 vs 拍 80 张，对比误差和重建时间，画一张小表。
- 试手机端 App 和桌面端 Meshroom 扫同一物件，比精度和易用性。
- 把模型导入 Blender（免费），量体积，和排水法测的体积比。

## 安全

- 拍摄时绕行注意脚下，别绊到电线或家具。
- 台灯别靠近易燃物，别长时间无人看管。
- 电脑重建时注意散热，别堵住出风口。
- 不拍摄他人隐私物品、不拍摄带个人信息的文件。上传到云端 App 前想清楚数据去哪了。
- 本实验不涉及激光、不涉及高处、不涉及化学品。
