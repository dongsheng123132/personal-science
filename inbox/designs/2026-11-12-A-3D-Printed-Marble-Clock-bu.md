# 3D 打印滚珠时钟：用滚珠拼出滚动文字

> 一句话说清你能亲手验证什么：用一排滚珠在斜面上滚落，按时间顺序落进格子，拼出可读的滚动文字——你能验证"滚珠下落时间是否可控、文字是否真的能读出来"。

| | |
|---|---|
| **需要** | 3D 打印机（或代打服务，待核实当地价格）；PLA 耗材约 200g；直径 6mm 钢珠 50 颗（待核实）；硬纸板/亚克力板 1 张；秒表（手机即可）；直尺；热熔胶枪 |
| **时间** | 一个周末（打印约 4–6 小时，组装 2–3 小时，调试 1–2 小时） |
| **花费** | ¥80–150（耗材 ¥30，钢珠 ¥20–40，代打费待核实；有打印机则更低） |
| **难度** | ★★★ |
| **验收** | 做之前写死：连续 10 次投放，至少 7 次滚珠能落进指定格子；滚动文字在 3 秒内完整显示一次，且旁人能读出至少 2 个字符 |

## 为什么值得做

滚珠时钟的原理不新：靠重力让滚珠沿轨道滚，用挡板或翻转机构控制落点。但"滚动文字"版本多了一层——滚珠不是随机落，而是按顺序落进一排格子，拼出字。这逼你解决两个真问题：**时间同步**（每颗珠子的下落时间要一致）和**空间编码**（格子位置对应字符笔画）。这两个问题都能用秒表和直尺量出来，不靠感觉。

## 怎么做

1. **设计格子**：在纸上画 5×3 的格子阵，每格能放一颗 6mm 钢珠。用格子拼出 2–3 个简单字符（如 "HI"、"3"）。格子间距 = 钢珠直径 + 1mm 余量。
2. **打印轨道**：打印一条倾斜 15°–20° 的直轨道，末端对准格子阵第一列。轨道宽度 = 钢珠直径 + 0.5mm。**先打一段 10cm 试件**，确认钢珠能顺畅滚下不卡。
3. **做投放机构**：最简单版——手动用镊子每 0.5 秒放一颗珠。进阶版——打印一个转盘，每转一格放一颗（转盘转速用手机秒表校准）。
4. **组装**：轨道固定在硬纸板上，格子阵在轨道末端下方。用热熔胶固定，留 1mm 调整余量。
5. **校准**：放 10 颗珠，秒表记录第 1 颗到第 10 颗的落格时间。算平均间隔。调整轨道角度或投放节奏，让间隔稳定在目标值（如 0.5 秒）。
6. **拼字**：按字符笔画顺序投放，滚珠依次落格。拍视频，回放看能否读出字。

## 算一下 / 会看到什么

- **理论下落时间**：斜面长 L、倾角 θ、摩擦系数 μ，滚珠加速度 a ≈ g(sinθ − μcosθ)。取 θ=18°、μ=0.3，a ≈ 9.8×(0.309 − 0.285) ≈ 0.24 m/s²。L=0.2m 时，t = √(2L/a) ≈ 1.3 秒。**实际会更快**，因为滚动摩擦小于滑动摩擦，μ 取 0.1 时 a ≈ 2.1 m/s²，t ≈ 0.44 秒。所以 0.5 秒间隔是合理目标。
- **你会看到**：前几次大概率卡珠或落格偏移。校准后，10 次里 7–8 次能落进目标格。滚动文字第一次播放时，旁人可能读不出——需要调格子间距或投放顺序。
- **验收判断**：10 次 ≥7 次落格成功 + 旁人读出 ≥2 字符 = 通过。否则调轨道角度或格子位置重来。

## 坑

1. **轨道太窄卡珠**：3D 打印有层纹，标称 6.5mm 实际可能 6.2mm。**先打试件量实际宽度**，留 0.5mm 余量。
2. **钢珠生锈**：普通钢珠受潮生锈，滚动变涩。买不锈钢珠，或涂薄层凡士林（会粘灰，慎用）。
3. **投放节奏不稳**：手动投放标准差常超 0.2 秒，文字会糊。**先用转盘机构**，别硬练手速。
4. **格子太密**：6mm 珠 + 1mm 间距 = 7mm 格距，5 列才 35mm 宽，字太小读不出。**放大到 8mm 珠或减到 3 列**。
5. **热熔胶堵轨道**：胶溢出到轨道面，珠会跳。**先固定再检查**，用美工刀刮平。

## 想再往前一步

- 加**光电传感器**（待核实型号）数落格次数，接 Arduino 自动记录时间，不用秒表。
- 做**双轨道**，两颗珠同时滚，拼两个字，验证同步性。
- 换**不同直径钢珠**（4mm/8mm），测下落时间随直径的变化，验证 a 与直径无关（理想情况）。

## 安全

- 钢珠小，**远离幼儿和宠物**，误吞风险。
- 3D 打印机工作时**别离人**，PLA 高温喷头会烫伤。
- 热熔胶枪头 150°C+，**别碰胶嘴**，胶未冷别用手按。
- 轨道倾角别超 30°，珠速过快会飞出伤人（尤其对眼睛）。**戴护目镜**。
