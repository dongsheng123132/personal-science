# 驻波：用一根绳子和手机测出波速

> 你能亲手让绳子“定住”成几段，数出节点数，算出波速，并验证它和张力、线密度的关系。

| | |
|---|---|
| **需要** | 棉绳或尼龙绳 3–5 m（直径 1–2 mm，具体型号待核实）；可挂重物的固定点（门把手、桌腿）；砝码或水瓶（装满水约 1 kg，可调）；手机（拍视频 + 慢放）；卷尺；秒表（手机自带）；可选：电动牙刷或小马达做固定频率振动源（型号待核实） |
| **时间** | 2–3 小时（含拍视频和算数） |
| **花费** | ¥0–50（绳子 + 水瓶，家里有就 0） |
| **难度** | ★★☆ |
| **验收** | ① 视频里能数出至少 3 个稳定节点；② 用 f = (n/2L)·√(T/μ) 算出的波速，与“波长×频率”直接测出的波速相差 ≤ 20%；③ 改变张力后，节点数按预期变化（张力增大→同样频率下节点变少或波长变长） |

## 为什么值得做

驻波是“波”这个概念里最容易被眼睛直接看见的一种。绳子两端固定，中间被驱动，某些频率下会形成不动的波形——节点不动，腹点上下摆。你能数节点、量间距、算波长，再用公式反推波速。整个过程不需要任何专业设备，手机慢放就够。

## 怎么做

1. **搭绳子**：一端系在固定点（门把手），另一端挂水瓶。绳子水平拉直，长度 L 用卷尺量，记下来。
2. **加张力**：水瓶装水，用厨房秤称总质量 m（或按 1 L ≈ 1 kg 估）。张力 T ≈ mg，g 取 9.8。
3. **驱动**：用手指拨、或用电动牙刷头轻触绳子一端附近，让绳子振动。找那个“波形定住”的频率——手拨时靠手感，牙刷靠它自带的固定频率。
4. **拍视频**：手机架稳，拍绳子全段，慢放（0.25× 或 0.125×）。数节点数 n（节点 = 不动点，包括两端）。
5. **量波长**：相邻节点间距 = λ/2。量 3 段取平均，得 λ。
6. **算频率**：如果用手拨，频率不好直接测——改用“数腹点个数 + 已知驱动频率”的路子。用电动牙刷时，查它标称频率（待核实，很多是 100–300 Hz 量级），或用一个已知频率的音叉/手机 App 发声驱动（App 频率可调，更可控）。
7. **换张力重做**：水瓶加水或减水，重复 3–6，记录 T 和 n 的变化。

## 算一下 / 会看到什么

- 理论波速：v = √(T/μ)。T 单位 N，μ 单位 kg/m。
- 波长：λ = 2L/n（n 为段数，即节点数减 1 的“半波数”）。
- 频率：f = v/λ = (n/2L)·√(T/μ)。
- 你会看到：张力越大，同样频率下能“定住”的段数越少（波长变长）；张力越小，越容易出多段。
- 验收对照：v_直接 = λ·f 与 v_理论 = √(T/μ) 相差 ≤ 20% 算过。差太多，先查 μ 和 T 的测量。

## 坑

- **绳子太粗或太软**：粗绳 μ 大、波速低，手拨很难出稳定波形。选细棉绳或尼龙绳。
- **固定点不牢**：门把手会晃，节点就不“死”。换桌腿或墙钩。
- **频率不对**：手拨是宽频，容易出杂波。用固定频率源（牙刷、App 发声）更稳。
- **视频角度斜**：斜拍会让节点间距量偏。手机镜头尽量垂直于绳子平面。
- **μ 估错**：绳子质量用厨房秤称，别用“大概”。μ 错 2 倍，波速错 1.4 倍。
- **水瓶晃动**：挂重物端要稳，别让它摆，否则张力在变。

## 想再往前一步

- 换不同绳子（不同 μ），固定 T 和 f，看 n 怎么变——验证 n ∝ 1/√μ。
- 用手机 App 发出可调频率，扫频找“共振点”，记录每个 n 对应的 f，画 f–n 图，斜率 = v/2L。
- 把绳子换成弹性绳，看波形是否还“定住”——讨论非理想绳的偏差。

## 安全

- 重物（水瓶）挂低，别挂在人头顶或通道。
- 绳子张力别拉太大，细绳崩断会抽人。手拨时轻触，别猛拉。
- 电动牙刷只碰绳子，别碰水或湿手操作。
- 拍视频时手机架稳，别边拍边拽绳。
