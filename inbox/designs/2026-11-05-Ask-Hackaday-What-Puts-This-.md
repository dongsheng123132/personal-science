# 实验：找出让照片变粉的那个环节

> 一句话说清你能亲手验证什么：用一台便宜摄像头拍同一张色卡，逐环节替换（光源、镜头、传感器、处理），定位"粉色偏色"到底出在哪一环。

| | |
|---|---|
| **需要** | 一台能拍 RAW 或至少能关自动白平衡的相机/手机（型号待核实，看你手上有什么）；一张自制色卡（打印的纯白、纯灰、纯红、纯绿、纯蓝五块，A4 纸即可）；一个固定光源（台灯即可，色温待核实，用手机 App 读一下）；三脚架或任何能固定相机的东西；一张黑卡纸（挡杂光） |
| **时间** | 一个下午（约 3–4 小时，含打印和搭台） |
| **花费** | ¥0–50（色卡自己打印，其余用家里现成的；若买灰卡约 ¥30，价格待核实） |
| **难度** | ★★☆ |
| **验收** | 做之前写死：在固定光源下，对同一色卡拍 5 组（每组改一个变量），每组算出白块与灰块的 R/G/B 比值。**若某组白块的 R/B 比值比基准组偏离超过 15%，就判定该环节是偏色主因。** 最终要能指名"是光源 / 镜头 / 传感器 / 处理管线中的哪一个"，并给出该组的比值数字。 |

## 为什么值得做

"照片发粉"是个经典问题，但网上答案基本靠猜。真正能定位的方法只有一个：控制变量，一次只改一样，用数字说话。这个实验不依赖任何特定型号，你今天拿手机就能重做。做完你会得到一张自己的"偏色归因表"，以后再遇到怪色，不用问人。

## 怎么做

1. **搭台**：相机固定，正对色卡，距离固定（比如 30 cm，用尺量）。光源固定位置和亮度。关掉房间其他灯。黑卡纸挡住光源直射镜头的杂光。
2. **关自动**：关自动白平衡、关自动曝光、关 HDR、关美颜。能拍 RAW 就拍 RAW，不能就拍最高质量 JPEG 并记下设置。
3. **基准组**：当前光源 + 当前镜头 + 当前设置，拍 3 张。记下每张白块中心 10×10 像素的平均 R/G/B。
4. **改光源**：换一个色温明显不同的灯（比如暖光换冷光），其余不动，再拍 3 张。
5. **改镜头**：如果手上有第二个镜头或手机另一颗摄像头，换上，光源回到基准，再拍 3 张。
6. **改处理**：同一张 RAW，用两个不同软件（或手机自带 vs 第三方）各导出一次，比较。
7. **算比值**：每组算白块 R/B、G/B，和基准组比。填进表里。

## AI 可以怎么帮你

- 帮你设计变量表：
  > "我要做一个相机偏色归因实验，变量是光源、镜头、传感器、处理管线。请帮我列一个控制变量表，每行一个组，列出该固定的量和该改的量，用 Markdown 表格。"
- 帮你写取色脚本：
  > "写一段 Python，用 PIL 读一张图，取指定坐标为中心 10×10 像素区域的平均 R/G/B，打印出来。要求能一次处理一个文件夹里所有图。"
- 帮你判断数据：
  > "这是 5 组白块的 R/G/B 平均值：[贴数据]。基准组是第 1 组。请算每组的 R/B 和 G/B，和基准比，指出哪组偏离最大，并说明这更可能指向光源、镜头还是处理管线。"
- 帮你排查异常：
  > "我的第 3 组数据 R 特别高，其他组正常。可能的原因有哪些？按可能性排序，每条给一个能在家里验证的方法。"
- 帮你写结论：
  > "根据以下归因表，帮我写一段 100 字以内的结论，说明偏色主因是哪一环，证据是哪组数字，不要下超出数据的结论。"

## 算一下 / 会看到什么

- 白块理想是 R≈G≈B。偏粉意味着 R 和 B 偏高、G 偏低，或 R/B > 1 且 G/B < 1。
- 算 **R/B** 和 **G/B** 两个比值就够，不用算绝对值。
- 典型预期：换光源那组偏离最大（光源色温直接影响 R/B）；换镜头那组偏离小；处理管线那组可能整体偏移但比例稳定。
- 如果所有组都偏粉且比例一致，问题在传感器或处理管线，不在光源。

## 坑

- **自动白平衡没关干净**：很多手机"专业模式"里还藏着自动。拍前拍后各拍一张白纸，比值变了就是没关。
- **光源不稳**：日光会变，别用窗边自然光。用台灯，拍完前别动它。
- **过曝**：白块过曝后 R/G/B 全顶到 255，比值失效。降曝光直到白块读数在 200 左右。
- **取色点偏了**：色卡没对准，取到边缘或阴影。用脚本固定坐标，别手点。
- **JPEG 压缩**：JPEG 会改颜色。能 RAW 就 RAW，不能就接受误差并在结论里写明。
- **只拍一张**：单张噪声大。每组至少 3 张取平均。

## 想再往前一步

- 用分光/色温 App 记录光源的实际色温，和算出的 R/B 做对照。
- 把同一张 RAW 喂给 3 个不同开源处理管线（如 dcraw、RawTherapee、darktable），看谁偏粉。
- 做一张"偏色指纹"：固定光源，换 5 个镜头，画出 R/B 随镜头变化的曲线。

## 安全

- 台灯别用裸露高功率灯泡，避免烫伤和眩光。
- 相机固定牢，别让它倒下来砸到灯或人。
- 不拆相机、不改电路。本实验只做外部拍摄和软件处理。
- 长时间盯屏幕算数据，定时休息。
