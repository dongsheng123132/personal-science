# 惠勒延迟选择实验（桌面版）

> 你能亲手看到：光子"走哪条路"的信息一旦被抹掉，干涉条纹就回来；一旦被保留，条纹就消失——而且这个"选择"可以在光子已经通过分束器之后才做。

## 为什么值得做

这是量子力学里最反直觉的实验之一，1979 年惠勒提出，后来被多次真实做出来。核心一句话：**光子"选路"还是"干涉"，取决于你最后怎么测它——哪怕这个决定是在它已经"通过"分束器之后才下的。**

你在家做的是它的"经典光"版本：用激光代替单光子。它不能证明单光子行为，但能让你亲眼看到"哪条路信息"和"干涉条纹"是互斥的——这是理解延迟选择的第一步。真正的单光子延迟选择需要单光子源和符合计数，家里做不了，这点必须说清楚。

## 怎么做

**第一步：先做普通双缝，拿到条纹（基准）。**
1. 暗室。激光笔固定在桌上，用橡皮泥压住，别让它滚。
2. 激光正对双缝片，距离缝 30–50 cm。缝后 1–2 m 放白屏。
3. 微调双缝片角度和位置，直到屏上出现清晰明暗条纹。手机拍照。
4. 用卷尺量：缝到屏距离 L、条纹间距 Δx。记下来。

**第二步：搭"哪条路"光路（马赫–曾德尔式）。**
1. 激光 → 半透半反镜（分束）→ 分成两路。
2. 两路各放一面小镜子，把光折回，在屏前**同一点汇合**。
3. 调两路光程，让它们在屏上重叠。这时屏上应出现干涉条纹（两路相干叠加）。
4. 这是"信息被抹掉"的状态：你无法知道光子走哪路。

**第三步：做"延迟选择"的对比。**
1. **保留信息**：在两路汇合前，各放一个挡板/狭缝，或让两路在屏上**错开不重叠**。此时你能判断光走哪路 → 条纹应消失。
2. **抹掉信息**：移开挡板，让两路重新重叠 → 条纹应回来。
3. 关键：把"挡/不挡"的动作放在光已经过分束镜之后（光程上就是"延迟"）。用手机录视频，慢放看条纹出现/消失。

**第四步：记录。** 每种状态拍 3 张照，量条纹间距，填进下表。

## 算一下 / 会看到什么

- 条纹间距：**Δx = λL / d**。λ≈650 nm，L=1.5 m，d=0.2 mm → Δx ≈ 4.9 mm。你量到 3.4–6.4 mm 都算过（±30%）。
- 对比度：**V = (Imax − Imin)/(Imax + Imin)**。有条纹时 V 应明显 > 0.3；"保留信息"状态 V 应 < 0.2。
- 会看到：两路重叠 → 明暗条纹；挡住一路或两路错开 → 均匀亮斑，条纹消失。
- **必须诚实**：连续激光下，"挡/不挡"只是改变光路，不是真的"光子已经过去再选择"。它演示的是原理，不是单光子延迟选择的严格实现。

## 坑

1. **光路对不准**：这是最大失败点。两面镜子角度差一点，两路就叠不上。先用一张纸在屏前逐段挡光，确认每段光路都通。
2. **激光不是单色/不是 TEM00**：便宜激光笔光斑有散斑，条纹会糊。换好一点的激光笔，或加一个小孔做空间滤波（针扎铝箔）。
3. **振动**：桌子一碰条纹就抖。用橡皮泥压死所有元件，别用手扶。
4. **环境光太亮**：不遮光，条纹对比度直接掉到看不见。纸箱罩住整个光路。
5. **把"两路不重叠"当成"信息保留"**：严格说这是空间分离，不是真正的 which-path 标记。写报告时要说明这一点，别夸大。
6. **以为看到了单光子行为**：连续光下你看到的是经典干涉，不是单光子。别在结论里写"验证了光子延迟选择"。

## 想再往前一步

- 用**单光子源**（如衰减到极弱的激光 + 单光子探测器）做真延迟选择——设备贵，待核实，超出本页预算。
- 用**空间光调制器或偏振片**做"量子擦除"版本：用偏振标记哪条路，再用检偏器"擦除"标记，看条纹回来。偏振片便宜，可试。

## 安全

- 激光笔 **<5 mW**，**绝不直视**，也绝不对着人眼或镜面反射方向看。戴激光防护镜更好（待核实型号）。
- 光路尽量低于视线，或加挡板，防止反射光射出桌面。
- 小镜子、玻璃片边缘可能割手，拿边不拿面。
- 暗室里走动先开灯再动，别绊倒。
- 不拆激光笔，不改电路。
