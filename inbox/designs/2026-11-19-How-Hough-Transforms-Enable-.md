# 霍夫变换：让电脑"看见"直线

> 你能亲手验证：一张手画的歪线照片，经过霍夫变换后，程序能不能把线的角度和位置找回来，误差在预设范围内。

| | |
|---|---|
| **需要** | 一台电脑（能装 Python）；手机或相机（拍照用）；白纸 A4；黑色马克笔或粗笔；直尺；可选：三脚架或把手机固定住的架子（待核实型号，家里有什么用什么） |
| **时间** | 一个下午（约 3–4 小时，含装环境和调参） |
| **花费** | ¥0–50（Python 免费；若需买马克笔/纸，约 ¥20；不买相机用手机即可） |
| **难度** | ★★☆ |
| **验收** | 对 3 张不同角度的直线照片，程序输出的直线角度与用量角器实测值之差 ≤ 3°；且每条线至少被检出 1 条。3 张全过算成功，否则算失败。 |

## 为什么值得做

霍夫变换是"从像素里找几何形状"的经典方法，1962 年就提出来了，今天还在用（车道线检测、文档扫描矫正、工业检测）。它不靠机器学习，规则清楚，你能一步步算出来、看出来。做完你会真正理解：为什么"一条线"在参数空间里是"一个点"，以及为什么它对噪声敏感。

## 怎么做

1. **画线**：在白纸上用直尺和粗笔画 3 条直线，角度分别大约 0°、45°、90°（相对纸边）。线要粗一点（2–3 mm），背景干净。
2. **量真值**：用量角器量每条线与纸底边的夹角，记下来。这是你的"标准答案"。
3. **拍照**：手机正对纸面拍，尽量别斜拍。3 张照片分别对应 3 条线（或一张拍全，但分开处理更简单）。
4. **装环境**：装 Python，然后 `pip install opencv-python numpy`（版本待核实，装最新稳定版即可）。
5. **预处理**：读图 → 转灰度 → 高斯模糊（核大小 5×5 起步）→ Canny 边缘检测（阈值先试 50/150，待你调）。
6. **跑霍夫**：用 `cv2.HoughLinesP`（概率霍夫，输出线段端点）。参数先设 `rho=1, theta=np.pi/180, threshold=50, minLineLength=50, maxLineGap=10`，再按结果调。
7. **算角度**：对每条检出的线段算 `atan2(dy, dx)`，转成角度，和步骤 2 的实测值比。
8. **记录**：把 3 组"实测 vs 程序"写进表格，判断是否满足验收标准。

## AI 可以怎么帮你

- **写代码骨架**：让 AI 给你一份能跑的完整脚本，你只改路径。
  > prompt：用 Python + OpenCV 写一个脚本：读入图片路径，转灰度、高斯模糊、Canny 边缘检测、cv2.HoughLinesP 检测直线，把每条线段的两个端点坐标和角度（度）打印出来，并在图上画出来保存。参数放在文件顶部方便改。加中文注释。

- **调参**：把失败现象贴给 AI，让它给调参方向。
  > prompt：我的霍夫直线检测结果：一条 45° 的粗黑线只检出 0 条，或检出很多短碎线。Canny 阈值是 50/150，HoughLinesP 参数 threshold=50, minLineLength=50, maxLineGap=10。请按"先改哪个、为什么"的顺序给我 5 个调参方案，每个说明预期效果。

- **解释原理**：让它用具体数字讲清参数空间。
  > prompt：用一张 100×100 像素的图、一条过点 (10,10) 和 (90,90) 的直线为例，手算说明它在 (rho, theta) 参数空间里对应什么，为什么多个点会交于一点。给出中间数值。

- **写验收脚本**：让 AI 帮你把"实测 vs 程序"自动比对。
  > prompt：写一个 Python 函数，输入两个角度（度），返回它们的最小夹角差（考虑 0/180 周期），并判断是否 ≤3°。再写一段把 3 组数据读进去、输出"通过/不通过"的代码。

- **排错**：报错直接贴。
  > prompt：运行这段 OpenCV 代码报错 [贴报错]。我的环境是 [Python 版本/系统]。请判断是安装问题还是代码问题，给出最小修复步骤。

## 算一下 / 会看到什么

- 一条直线在霍夫空间里是一个点 `(rho, theta)`。`theta` 是法线方向，线的方向 = `theta + 90°`。
- 你检出的线段角度和实测角度差 ≤ 3°，说明参数空间分辨率（`theta` 步长 1°）够用。
- 常见现象：线越粗、边缘越糊，检出的线段越多越碎；`threshold` 调高会只剩最明显的线，调低会冒出噪声线。
- 如果 3 张里 2 张过、1 张不过，先看不过的那张是不是拍斜了或光照不均——这本身就是结论。

## 坑

- **拍斜了**：手机没正对纸面，直线在图像里被透视拉歪，角度全错。用架子或把手机贴桌面拍。
- **Canny 阈值乱设**：太低边缘全是噪点，太高线断成几截。先看边缘图再调霍夫。
- **`theta` 分辨率**：用 `np.pi/180` 是 1° 步长，验收卡 3° 够用；想更准改 `np.pi/360`，但更慢。
- **`minLineLength` 太大**：短线直接检不出。先设小一点看结果，再往上收。
- **把"检出线段数"当成功**：验收标准是角度误差，不是线越多越好。
- **光照不均**：纸面有阴影会让边缘检测偏。均匀光、别开闪光灯直打。
