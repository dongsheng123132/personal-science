# 埃拉托色尼：用一根杆子的影子测地球半径

> 两个人在两个城市，同一天正午各量一次杆影，就能算出地球半径，误差能压到 5% 以内。

| | |
|---|---|
| **需要** | 两根直杆（扫帚柄、PVC 管、晾衣杆都行，长度 ≥ 1 m，越长约精确）；卷尺（≥ 3 m）；水平仪或手机水平仪 App；铅垂线（一根线 + 一个螺母）；粉笔/胶带；两个相距 ≥ 300 km 的人；手机（对时 + 通信）；晴天 |
| **时间** | 准备 1 天 + 测量 1 个正午 + 计算 1 小时（一个周末够） |
| **花费** | ¥0–100（杆子和卷尺家里多半有；没有就买，卷尺约 ¥20–40，PVC 管约 ¥10–20。具体型号价格待核实） |
| **难度** | ★★☆ |
| **验收** | 算出的地球半径落在 **5800–7000 km** 之间（真值约 6371 km，即误差 ≤ 10%）。做之前就写死这条。 |

## 为什么值得做

- 公元前 240 年，埃拉托色尼只用影子就算出了地球半径。没有卫星，没有激光，没有离开地面。
- 今天你两个人、一个下午就能重做。这不是"复述历史"，是你自己量出来的数。
- 它同时验证两件事：地球是球（否则两地正午太阳高度角不会差那么多），以及这个球有多大。
- 全程只有一个可测量：**杆影长度**。没有玄学。

## 怎么做

**核心原理**：同一天正午，两地太阳高度角之差 = 两地纬度之差。知道两地大圆距离，就能按比例推出整个地球周长。

1. **选两个点。** 两人相距 ≥ 300 km，最好在同一经线附近（南北排列）。距离越远，角度差越大，误差越小。用手机地图量两地直线（大圆）距离，记下来，记为 `D`。
2. **约好同一天。** 选一个两人都晴天的日子。提前查两地天气。
3. **对时。** 约定"当地太阳正午"各自测。太阳正午 = 影子最短的那一刻，不是钟表 12:00。两人各自提前 20 分钟开始，每 2 分钟量一次影长，取最短的那次。
4. **立杆。** 杆子垂直地面。用铅垂线检查：从杆顶垂线，线应贴着杆身。地面用水平仪确认水平。杆子露出地面的长度记为 `L`，用卷尺量，精确到 mm。
5. **量影。** 影子末端到杆底的距离记为 `s`。同样精确到 mm。影子要落在平地上，别落在台阶或草丛里。
6. **各测 3 次取平均。** 两人都做。
7. **算太阳高度角。** 每地：`tan(θ) = s / L`，所以 `θ = arctan(s / L)`。用计算器或让 AI 算。
8. **求角差。** `Δθ = |θ₁ − θ₂|`（单位：度）。
9. **推地球周长和半径。**
   - 周长 `C = D × 360 / Δθ`
   - 半径 `R = C / (2π)`
10. **对照验收标准。** `R` 在 5800–7000 km 之间就算成功。

## AI 可以怎么帮你

1. **算大圆距离和角差。** 你报两地经纬度，让 AI 算距离和预期角差，用来预判你的测量是否离谱。
   > 我在北纬 39.90°、东经 116.40°，我朋友在北纬 31.23°、东经 121.47°。请算两地大圆距离（km），并估算同一天正午太阳高度角之差（度）。给出计算过程。

2. **把原始数据变成结果。** 你把杆长、影长丢给它，让它算角度、周长、半径、误差。
   > 杆长 L1=1.500 m，影长 s1=0.412 m；另一地 L2=1.500 m，影长 s2=0.180 m；两地大圆距离 D=1067 km。请算两地太阳高度角、角差、地球周长、地球半径，并与 6371 km 比较误差百分比。逐步写。

3. **诊断异常值。** 结果偏得离谱时，让它帮你列出可能原因并排序。
   > 我算出地球半径 4200 km，明显偏小。两地距离 1067 km，角差算出 14.6°。请列出最可能导致半径偏小的 5 个原因，按可能性排序，并说明每个怎么检查。

4. **生成测量记录表。** 让它给你一张能打印的表格，避免现场乱记。
   > 给我做一张 A4 可打印的野外测量记录表，包含：地点、经纬度、日期、杆长、每 2 分钟一次的影长记录（共 11 行）、最短影长、计算出的太阳高度角、签名栏。用 Markdown 表格。

5. **核对太阳正午时间。** 让它帮你估算当地太阳正午大概在几点，方便你安排到场时间。
   > 我在东经 116.40°，时区 UTC+8。请估算今天当地太阳正午大约在钟表几点几分，并说明这个估算的误差来源。

## 算一下 / 会看到什么

**一个真实量级的例子**（数字是示意，你的会不同）：

- 北京：`L = 1.500 m`，正午最短影长 `s₁ = 0.412 m` → `θ₁ = arctan(0.412/1.500) ≈ 15.4°`
- 上海：`L = 1.500 m`，正午最短影长 `s₂ = 0.180 m` → `θ₂ = arctan(0.180/1.500) ≈ 6.8°`
- 角差 `Δθ ≈ 8.6°`
- 两地大圆距离 `D ≈ 1067 km`
- 周长 `C = 1067 × 360 / 8.6 ≈ 44,700 km`
- 半径 `R = 44,700 / (2π) ≈ 7,100 km`

真值 6371 km，这个例子偏大约 11%，刚好卡在验收线外——说明**影长量到毫米、两地尽量南北排列**很关键。你实际做，目标是把误差压到 10% 以内。

**你会看到**：纬度差越大，两地正午影长差越明显。这就是"地球是弯的"最直接的证据。

## 坑

1. **不是同一天。** 两人日期差一天，太阳赤纬变了，角差就废了。必须同一天。
2. **不是正午。** 用钟表 12:00 测，东西方向的距离会污染结果。必须找影子最短那一刻。
3. **杆不垂直。** 杆歪 1°，影长就偏。用铅垂线，别用眼睛估。
4. **两地东西排列。** 两人几乎同一纬度、只差经度，正午太阳高度角几乎一样，角差趋近 0，算出来爆炸。**尽量南北排列。**
5. **影长量到厘米级。** 杆越长、影越长，相对误差越小。1.5 m 的杆比 0.5 m 的杆好得多。
6. **地面不平 / 影子落在斜坡上。** 影子要落在水平地面上。
7. **拿"城市中心"当坐标。** 两地距离要用你实际立杆的位置算，不是市中心。
8. **忘了记录单位。** 杆长和影长必须同一单位，全程用米。

## 想再往前一步

- **加第三个点。** 三人三地，两两算一遍，看结果是否一致。一致说明方法稳。
- **换季节重做。** 冬至和夏至各做一次，看结果是否稳定。
- **不用大圆距离，改用纬度。** 用手机 GPS 读两地纬度，`Δφ` 直接当角差，对比两种算法的差异。
- **误差分析。** 把影长 ±2 mm 的误差传进去，看半径结果能摆动多少。这比一个数更有说服力。
- **复刻埃拉托色尼原版。** 用"亚历山大港到赛伊尼"的古代距离数据重算，看古人得到什么数。

## 安全

- 正午户外，**防晒**：帽子、长袖、防晒霜。别在烈日下站一小时。
- **别直视太阳。** 全程只看影子，不看太阳。
- 杆子立稳，防止倒下砸人。高处作业不需要，别爬。
- 卷尺回弹会割手，慢慢放。
- 夏天正午地面烫，穿鞋。
- 两人异地，各自注意当地天气和路况，别为测影子跑危险的地方。
