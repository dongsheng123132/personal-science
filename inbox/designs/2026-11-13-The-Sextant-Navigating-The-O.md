# 六分仪：用一把尺子和一面镜子找到自己的纬度

> 你能用自制或廉价六分仪测出北极星高度角，算出所在纬度，误差在 ±1.5° 以内。

| | |
|---|---|
| **需要** | 六分仪（自制：硬纸板/木板 + 小镜子 ×2 + 半透半反镜片或透明塑料片 + 量角器 + 细绳 + 重物；或买塑料教学六分仪，型号待核实）· 北极星（肉眼可见，无需器材）· 手电筒（红光更好）· 铅笔和纸 · 手机指南针（仅用于找北，不用于测量）· 卷尺（可选） |
| **时间** | 一个晚上（约 2 小时，含制作）；晴朗无月的夜晚 |
| **花费** | ¥0–150（自制接近 ¥0；买教学六分仪约 ¥50–150，价格待核实） |
| **难度** | ★★☆ |
| **验收** | 连续 3 次独立测量北极星高度角，取平均，与当地真实纬度（手机 GPS 或地图查得）之差 ≤ 1.5°；且 3 次读数极差 ≤ 1° |

## 为什么值得做

GPS 告诉你答案，但不告诉你答案从哪来。六分仪是唯一一个靠纯几何、不靠电、不靠信号就能定位的工具，用了两百多年。你自己做一次测量，会真正理解"纬度"不是地图上的线，而是你头顶那颗星的高度角。这个实验还顺便验证一件事：在没有 GPS 的情况下，人类确实能知道自己在哪。

## 怎么做

**第一步：做六分仪（约 40 分钟）**

1. 找一块硬纸板或薄木板，裁成约 20 cm × 25 cm 的扇形（圆弧半径约 20 cm）。
2. 在圆弧边缘贴一条量角器刻度纸（打印或手画，0°–90° 即可）。
3. 在扇形顶点固定一根细绳，绳端挂一个小重物（螺母、钥匙都行）。这是铅垂线，用来读角度。
4. 在顶点附近装一面小镜子（A 镜），镜面朝外，与扇形平面成约 45°。
5. 在圆弧中点附近装第二面小镜子（B 镜），半透半反（用透明塑料片贴一半锡纸也行）。B 镜用来同时看到"地平线"和"星星"。
6. 检查：眼睛贴近 A 镜，转动扇形，直到 B 镜里地平线和星星重合。此时铅垂线在刻度上的读数就是高度角。

> 自制六分仪的精度取决于刻度画得准不准。画刻度时用直尺和量角器，别手估。

**第二步：找北极星（约 10 分钟）**

1. 面朝北。用手机指南针确认方向，然后放下手机。
2. 找北斗七星（大熊座），沿勺口两颗星连线延长约 5 倍，就是北极星。
3. 北极星很暗，但位置几乎不动。找不到就用手机星图 App 辅助定位（App 只用来找星，不用来测量）。

**第三步：测量（重复 3 次，每次间隔几分钟）**

1. 眼睛贴近 A 镜，转动六分仪，让 B 镜里出现地平线和北极星。
2. 微调，直到星点正好落在地平线上。
3. 让铅垂线稳定（等 2–3 秒不晃），读刻度，记录。
4. 重复 3 次。每次重新对星，不要看上次读数。

**第四步：算纬度**

北极星高度角 ≈ 观测者纬度（北半球，误差约 ±0.7°，因为北极星不完全在天极上）。所以读数直接就是纬度估计值。

## AI 可以怎么帮你

1. **帮你画刻度纸**：让 AI 生成一张 0°–90° 的扇形刻度模板，打印后贴到纸板上。
   > "帮我生成一张适合 A4 打印的六分仪刻度纸，扇形半径 20 cm，0° 到 90°，每 1° 一个刻度，每 5° 标数字。用 SVG 或可打印的 HTML/CSS 输出。"

2. **帮你排查测量误差**：把读数发给 AI，让它分析偏差来源。
   > "我用自制六分仪测北极星高度角，三次读数是 38.2°、39.5°、37.8°，当地真实纬度是 39.1°。请帮我分析：极差 1.7° 可能来自哪些操作误差？我该怎么改进？"

3. **帮你算当地纬度对照**：让 AI 根据你所在城市给出真实纬度，并解释北极星高度角与纬度的偏差。
   > "我在[城市名]。请告诉我当地纬度，并解释为什么北极星高度角不完全等于纬度，偏差大概多少度。"

4. **帮你设计改进版六分仪**：如果第一次精度不够，让 AI 给结构改进建议。
   > "我的自制六分仪读数不稳定，铅垂线晃得厉害，B 镜里星点和地平线很难同时看清。请给我 3 个低成本改进方案，材料限制在 ¥50 以内。"

5. **帮你验证几何原理**：让 AI 用图解释为什么六分仪读的是高度角。
   > "用文字加简单示意图解释六分仪的几何原理：为什么当 B 镜里星点和地平线重合时，铅垂线读数等于星星的高度角？"

## 算一下 / 会看到什么

- 北极星高度角 ≈ 纬度。北纬 40° 的地方，读数应在 39°–41° 之间。
- 验收标准：3 次读数平均与真实纬度差 ≤ 1.5°，极差 ≤ 1°。
- 如果读数系统性偏高或偏低（比如每次都差 3°），多半是刻度纸贴歪了或铅垂线没对准顶点，不是星星的问题。
- 北极星本身偏离天极约 0.7°，所以即使仪器完美，也会有约 ±0.7° 的固有误差。这是物理限制，不是你的错。

## 坑

1. **刻度纸贴歪**：这是最常见的失败原因。贴之前用铅垂线校准 0° 线，确认顶点、铅垂线、刻度 0° 三点对齐。
2. **铅垂线晃**：重物太轻或绳子太细都会晃。用螺母或钥匙，等 2–3 秒再读。
3. **B 镜里看不清地平线**：夜间地平线很暗。找一处有远处灯光或海平面的方向，或者等月亮刚升起时测（但别让月光直射镜子）。
4. **把手机当测量工具**：手机指南针和水平仪精度不够，只能用来找北和辅助，不能替代六分仪读数。
5. **只测一次就下结论**：单次读数受手抖和视线影响很大。必须重复 3 次。
6. **选错星**：北极星很暗，容易和附近其他星混淆。先用星图 App 确认，再放下手机测。

## 想再往前一步

- **测太阳高度角定正午**：白天用六分仪测太阳高度角（必须用滤光片，别直视太阳），记录一天中最大值出现的时刻，那就是当地正午。
- **做一次"双星定位"**：同时测北极星和另一颗已知赤纬的星，用球面三角算经纬度。这需要查星表，AI 可以帮你算。
- **对比 GPS**：把你的纬度估计和手机 GPS 读数对比，画一张误差图。看看误差是随机的还是系统的。

## 安全

- **绝对不要直视太阳**。测太阳必须用合格滤光片（如巴德膜），没有就不测。自制滤光片不可靠，别赌。
- 夜间户外注意脚下，带手电（红光模式保护夜视）。
- 镜子别对着来车方向反光。
- 冬季户外注意保暖，别在阳台边缘探身测量。
- 本实验不涉及明火、化学品、高处作业。
