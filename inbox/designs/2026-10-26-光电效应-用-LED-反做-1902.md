# 光电效应（用 LED 反做）：用几块钱的 LED 测出普朗克常数

> 给不同颜色的 LED 加反向电压，测出它刚好不亮时的电压，反推出普朗克常数 h，看它落不落在 6.0–7.5×10⁻³⁴ J·s 之间。

## 为什么值得做

这是最便宜的"量子实验"。原理一句话：LED 发光是电子从高能级掉到低能级，放出一个光子，光子能量 E = hν。反过来，给它加反向电压，电压大到能把电子"顶回去"，它就不亮了。这个临界电压 V₀ 满足 eV₀ ≈ hν（忽略一个小的修正项，见下文）。所以：**测电压 + 查 LED 波长 → 算 h**。1902 年勒纳德做的是真光电效应，今天你用 LED 反着做，同样的物理，几十块钱。

## 怎么做

1. **查每个 LED 的波长。** 买的时候记下颜色标称波长（红 ~625nm、黄 ~590nm、绿 ~525nm、蓝 ~470nm、紫 ~405nm，**具体以你买的批次为准，待核实**）。没有标称就用手机拍光谱 App 粗测，或查该颜色典型值并记下不确定度。
2. **搭电路。** 电源 → 1kΩ 限流电阻 → LED → 万用表（并联在 LED 两端测电压）→ 回电源。注意 LED **反向**接（长脚接正、短脚接负是正向；这里要反接，让它处于"该亮却不亮"的方向）。具体接法以你手头 LED 的极性为准，先用正向试亮确认极性。
3. **遮光。** 用纸筒或黑胶带把 LED 罩住，只留一个小孔观察。环境光越暗，判断"刚好不亮"越准。
4. **从 0V 慢慢升压。** 每次升 0.01–0.02V，盯着 LED。记录**它刚开始微亮**时的电压，这就是 V₀。升太快会错过临界点。
5. **每个 LED 测 3 次**，取平均。换下一个颜色，重复。
6. **记录表：** 颜色 / 波长 λ(nm) / 频率 ν=c/λ(Hz) / 临界电压 V₀(V) / 3 次读数。

## AI 可以怎么帮你

1. **帮你算频率和拟合。** 把数据贴给 AI，让它算 ν、做 V₀–ν 线性拟合、给出斜率和 h。
   > prompt：`我有 5 组数据：(波长nm, 临界电压V) = [(625,1.9),(590,2.1),(525,2.4),(470,2.7),(405,3.1)]。请算频率 ν=c/λ（c=3e8 m/s），做 V₀ 对 ν 的线性拟合，斜率 k，然后 h = k·e（e=1.602e-19 C），给出 h 和 R²。`
2. **帮你判断接线对不对。** 描述你的电路，让 AI 检查极性。
   > prompt：`我用 9V 电源、1kΩ 电阻、一个 5mm 红色 LED 搭反向偏置电路测临界电压，万用表并联在 LED 两端。请检查：LED 应该正接还是反接？万用表红黑表笔怎么接？`
3. **帮你设计记录表和数据检查。** 
   > prompt：`帮我做一个 LED 测普朗克常数的实验记录表模板，包含颜色、波长、频率、3 次临界电压读数、平均值、备注，用 Markdown 表格。`
4. **帮你解释偏差。** 结果算出来偏大或偏小，让 AI 列可能原因。
   > prompt：`我用 LED 反向电压法测普朗克常数，算出来 h=8.2e-34，比真值 6.626e-34 大 24%。可能的原因有哪些？按可能性排序，并说明每个怎么排查。`
5. **帮你写结论段。** 
   > prompt：`根据我的拟合结果 h=6.9e-34 J·s，R²=0.97，帮我写一段 150 字的实验结论，说明是否在验收范围内、主要误差来源。`

## 算一下 / 会看到什么

- 频率：ν = c / λ，c = 3.0×10⁸ m/s。
- 临界电压与频率近似线性：**V₀ ≈ (h/e)·ν − 修正项**。修正项来自 LED 的禁带宽度和接触电势，通常让截距不为零，但**斜率仍然给出 h/e**。
- 所以：**h = 斜率 × e**，e = 1.602×10⁻¹⁹ C。
- 预期：红光 V₀ 最低（~1.8–2.0V），紫光最高（~3.0–3.3V）。**具体数值随 LED 批次变化，待核实，以你实测为准。**
- 拟合 V₀ 对 ν，斜率单位 V/Hz，乘 e 得 J·s。看 h 是否落在 6.0–7.5×10⁻³⁴。

## 坑

- **临界点判断主观。** "刚好不亮"和"刚开始亮"差 0.05V 很正常。对策：遮光、慢升压、每色测 3 次取平均。这是最大误差源。
- **LED 波长标称不准。** 标称 625nm 实际可能 630nm。对策：记下不确定度，或用光谱 App 粗测。
- **接反了。** 正向接会直接亮，测不到临界电压。先正向试亮确认极性，再反接。
- **电源分辨率不够。** 只能 0.1V 步进的话，临界点误差大。对策：用能到 0.01V 的电源，或加电位器细调。
- **环境光干扰。** 白天窗边测，微亮根本看不见。对策：暗处、纸筒遮光。
- **只测 2–3 个颜色。** 点太少拟合不可靠。至少 5 个颜色，R² 才有意义。

## 想再往前一步

- 加更多颜色（橙、青、白），看拟合是否更稳。
- 用同一颜色不同批次的 LED，看 V₀ 是否一致（检验"波长决定电压"）。
- 把限流电阻换成不同值，看 V₀ 是否变化（应该几乎不变，若变说明电路有问题）。
- 查 1902 年勒纳德原始论文的装置，对比你的"反向"做法和"正向"光电效应的异同。

## 安全

- 电压 ≤ 12V，电流 ≤ 10mA，**无触电风险**，但别短路电源。
- LED 长时间正向大电流会发热，限流电阻别省。
- 焊接若用到烙铁：通风、别碰烙铁头、用完断电。
- 别在潮湿桌面操作。电源用电池最省心。
- 本实验不涉及激光、高压、化学品。
