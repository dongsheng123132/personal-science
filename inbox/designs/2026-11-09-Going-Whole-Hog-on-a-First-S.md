# 用 ¥150 的 RTL-SDR 接收 NOAA 气象卫星云图

> 你能亲手收到一颗卫星发来的信号，并把它解码成一张云图。

| | |
|---|---|
| **需要** | RTL-SDR 接收棒（RTL2832U + R820T2 芯片，型号待核实，买前确认支持 137 MHz）· 无源偶极子天线（多数套件自带，待核实）· 电脑（Win/Linux/Mac 均可）· 一根 2 米左右的同轴延长线（可选）· 免费软件：SDR#（Windows）或 GQRX（Linux/Mac）+ SatDump（解码） |
| **时间** | 一个下午装软件 + 一个周末等过境 |
| **花费** | ¥100–150（RTL-SDR 套件，价格随渠道浮动，待核实） |
| **难度** | ★★☆ |
| **验收** | 在 SatDump 里得到一张至少 200 行、能看出陆地/云层轮廓的 NOAA APT 图像，且图像顶部时间戳与你的接收时间一致 |

## 为什么值得做

这是最便宜的“从太空收信号”入门。NOAA 15/18/19 三颗卫星在 137 MHz 附近持续发 APT 模拟图像，功率大、信号强，一根简陋天线就能收到。你验证的不是“我买了个玩具”，而是：**电磁波真的从 800 公里外传过来了，而且我能把它变成像素**。整个链路——天线→调谐→解调→解码——每一环你都能亲手碰。

## 怎么做

1. **装软件**。Windows 装 SDR# 和 SatDump；Linux 装 GQRX 和 SatDump。先确认 SDR 棒能被识别（SDR# 里能看到频谱噪声底）。
2. **查过境**。用 SatDump 自带的过境预测，或 Heavens-Above 网站，找未来 24 小时内 NOAA 15/18/19 中**仰角 > 30°** 的一次过境。记下开始时间和频率（NOAA 15: 137.620 MHz；18: 137.9125 MHz；19: 137.100 MHz，频率待核实，以 SatDump 显示为准）。
3. **架天线**。偶极子天线拉直，两臂成 120° V 形，放在窗外或阳台，尽量朝天空、远离金属栏杆和电脑。天线到 SDR 的线越短越好。
4. **预调**。过境前 5 分钟，在 SDR# 里调到该频率，带宽设 40–50 kHz，看噪声底。过境开始时你会看到一条斜着扫过的信号。
5. **录**。用 SDR# 的 baseband recorder 录 IQ 数据（或直接用 SatDump 的 live 模式边收边解）。录整个过境，通常 10–15 分钟。
6. **解码**。把 IQ 文件丢进 SatDump，选对应卫星的 APT 解码器，输出 PNG。
7. **对时间**。看图像顶部的时间戳，和你录制的实际时间比对。

## 算一下 / 会看到什么

- **波长**：137 MHz → λ ≈ 2.19 米。半波偶极子每臂约 55 cm。套件天线通常就是这个量级，不用改。
- **过境时长**：仰角 30° 以上的过境约 8–12 分钟，仰角越高越长。
- **图像**：NOAA APT 每行 2080 像素，每秒 2 行。一次 10 分钟过境约 1200 行。验收要求 ≥200 行，是留了余量。
- **你会看到**：一条从左上到右下的斜扫描线逐渐变成灰度图像；好的时候能看出海岸线、云团、甚至城市轮廓。图像会有噪点和斜纹，正常。

## 坑

1. **天线放室内**。混凝土墙和金属窗框会把 137 MHz 信号吃掉大半。必须放窗外或阳台。
2. **频率调错**。NOAA 15/18/19 频率不同，且有多普勒频移（过境中偏移可达 ±3 kHz）。用 SatDump 的自动跟踪，别手动死调。
3. **增益开太大**。RTL-SDR 增益拉满会过载，信号反而糊。从中等增益开始试。
4. **采样率不匹配**。SatDump 解码要求特定采样率（通常 48k 或 1.024M，待核实），录之前确认设置。
5. **电脑 USB 供电不足**。长延长线 + 廉价 hub 会导致丢样本。直接插电脑 USB 口。
6. **过境仰角太低**。仰角 < 15° 的过境信号穿过大气路径太长，基本收不到清晰图像。第一次选高仰角。

## 安全

- 接收是被动的，不发射，无射频暴露风险。
- 天线架在窗外时固定好，别掉下去砸人。
- 雷雨天不要架天线在室外，拔掉 SDR。
- 长时间盯屏幕注意休息。
