# Awesome 实验 · Personal Science

> **科研平权。** 让没有实验室、没有学历、没有经费的人，也能亲手做出真实验。

一个人在家就能做的实验清单。不用实验室、不用学历、不用申请。
**一个人 = 一个实验室。** 宗旨见 [章程](CHARTER.md)。

每个实验都写清楚四件事：**要什么、多久、怎么算做成了、坑在哪**。
做完了把结果提上来（[RESULTS.md](RESULTS.md)），给下一个人少走几小时弯路——**失败的结果也一样收**。

没有评分，没有认证，没有审核。挑了就能玩。

## 怎么加一个

三条要求，见 [CONTRIBUTING.md](CONTRIBUTING.md)：

1. **个人在家能做完**：预算 ≤ ¥200，时间 ≤ 一个周末，不需要资质和危险操作
2. **写清楚怎么算做成了**：验收标准要能在做之前写死
3. **写清楚坑和危险**：包括"这条别做"

宁缺毋滥。一个真能玩的实验，胜过二十条链接。

## 安全底线

这个清单不做这些：高压电、明火、化学品入口/吸入、活体动物实验、需要资质的检测、任何会伤到人的操作。

看到心动但感觉危险的，别做，先开个 issue 问问。
